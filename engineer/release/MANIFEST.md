## Exclusions -- what is NOT in this package, and why

- **engineer/data/*per-cell*.json (baseline_/random_/ext_cmaes_/ext_random_)** -- Raw per-cell result JSONs (~500 MB, carry machine-specific harness.deps provenance paths). Aggregated into the shipped scoreboards; deferred to a separate DOI-deposited data package.
- **engineer/data/trajectories.jsonl, engineer/data/ext_trajectories.jsonl** -- (state, action, outcome, cost) trajectory logs (>100 MB each). Deferred to the separate data deposit; regenerable by running the drivers.
- **lna/ (the shared core: datastore, spec, size, extract, to_spice, topology, moves, null_sizer, playbook, ref/, specs/)** -- Lives on main; a runtime dependency, not bundled here. The env imports it at runtime. Fetch the circuit-repro repo's main branch (see README).
- **45nm BSIM4 model card (AutoCkt .../spice_models/45nm_bulk.txt)** -- NOT bundled and NOT auto-fetched. License status UNKNOWN (no header; no LICENSE in the AutoCkt clone). Manual fetch from ksettaluri6/AutoCkt at the pinned SHA -- see README quickstart.
- **VACASK (harmonic-balance simulator)** -- AGPL-3.0; out of scope. HB cross-check results are cited (case study, later release); build procedure is in PORTING.md. Not required to run the benchmark.
- **dhruva case study (lna/FINDINGS.md, JOURNEY.md, playbook entries)** -- Staged for a later release per the E-5 ruling; environment + benchmark only in this package.
