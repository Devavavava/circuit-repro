==== ANSWER t2-nb090-noise-0047 ====
1. DIAGNOSIS
The binding failure is wideband stability (mu over 0.01-50 GHz = 0.68), with gain also slightly short (9.34 vs 9.99 dB). The drain load is L1 in series with R2. Above the shunt-peaking corner, L1 makes the load inductive. With an inductive load Z_L = jwL, the Miller admittance through Cgd (and through the feedback path R1) is Y_in = jwCgd(1 + gm*Z_L), which contains a NEGATIVE real term -w^2*gm*L*Cgd. The gate/input port therefore shows negative resistance at multi-GHz frequencies, where the 45 nm device still has plenty of gain, and mu drops below 1 out of band. At the same time the gain is capped: with a single NMOS at a fixed Idd, the only transconductance is gm_n, and the DC-dropping resistor R2 (part of the load) sits in parallel with the 50-ohm port. The optimizer therefore can't raise gain without making the load more inductive, which is the very thing that hurts stability.

2. EDIT: replace the inductively loaded NMOS CS with a self-biased current-reuse CMOS inverter under the same resistive shunt feedback (the inverter-based resistive-feedback LNA). PM1 is the active load and also adds its gm (gm_n + gm_p at the same current). The inductor is removed, so no element can make the drain load inductive. R1 still sets the self-bias (Vg = Vd, inverter trip point) and the broadband real input match.
```netlist
C C1 VIN1 n1
R R1 n1 n2
NMOS NM1 n2 n1 VSS VSS
PMOS PM1 n2 n1 VDD VDD
C C2 n2 VOUT1
```
3. PREDICTION: mu_min_wide_0.01-50GHz improves from 0.68 to about 1.2 (+0.5 or more; it should pass). With no inductive load, Re(Y_in) stays positive, and the loop is single-pole and RC-only up to fT. Side effect: s21 should rise by about 2-4 dB from the doubled gm at the same Idd, which also clears the gain gate. NF stays below about 2 dB.

==== ANSWER t2-nb090-noise-0350 ====
1. DIAGNOSIS
The binding failure is the input match (s11 = -2.3 dB). C1 feeds the bare gate of NM1, so at 900 MHz the input impedance is basically 1/(jwCgs) in parallel with the large bias-feed resistor R2. It is a mostly reactive, high-Q capacitive impedance with almost no real part near 50 ohm, so |Gamma| is close to 1. Nothing in the circuit synthesizes a resistive input. The mismatch also costs about 4 dB of transducer gain, and stage 1 gets no passive voltage gain from an input resonance. That is a large part of why s21 is 15 dB against 22.8 dB required. Making R2 small to get a real part would ruin the 1.15 dB NF budget.

2. EDIT: convert the stage-1 input to the classic inductively degenerated CS match: series gate inductor Lg (L4) between the DC block and the gate, and source-degeneration inductor Ls (L5) from NM1 source to ground. Ls synthesizes a NOISELESS real part Re(Zin) = wT*Ls = 50 ohm, and Lg + Ls resonate out Cgs at 900 MHz. The interstage series inductor L2 is removed so the circuit stays within the 4-inductor budget. L1 still tunes the stage-1 drain together with Cgs2, and C2 still couples directly into the NM2 gate. The bias is unchanged (mirror through R2/R3).
```netlist
C C1 VIN1 n0
L L4 n0 n1
NMOS NM1 n2 n1 n8 VSS
L L5 n8 VSS
L L1 VDD n2
C C2 n2 n5
NMOS NM2 n6 n5 VSS VSS
L L3 VDD n6
C C3 n6 VOUT1
R R1 VDD n7
NMOS NM3 n7 n7 VSS VSS
R R2 n7 n1
R R3 n7 n5
```
3. PREDICTION: s11_max_db improves from -2.3 dB to about -10 to -12 dB (about 8-10 dB better; it passes the -7.85 dB gate). Side effects: s21 rises by about 5-7 dB (mismatch loss recovered, plus the input-resonance Q boost at the gate), and NF stays about 1.1 dB because inductive degeneration is the noise-optimal match. Mu_wide should also improve because the high-Q series L2/Cgs2 interstage resonance is gone and Ls adds a positive input real part.

==== ANSWER t2-wb1020-gain-0183 ====
1. DIAGNOSIS
The binding failure is wideband stability (mu over 0.01-50 GHz = 0.71), and s21 is also short (9.6 vs 12.0 dB). The drain load is L1 (shunt peaking) in series with R2. Above the peaking corner the load goes inductive. The Miller admittance through Cgd and the feedback path, Y_in = jwCgd(1 + gm*jwL), then has a negative real part (-w^2*gm*L*Cgd), so the device shows negative input resistance at several GHz while it still has gain, and mu < 1. Gain is capped because one NMOS supplies all the gm at the Idd cap, and the load-side R2 (needed to drop the DC) shunts the 50-ohm output. Raising gain would mean more inductive peaking, which destabilizes the circuit further.

2. EDIT: replace the shunt-peaked NMOS CS with a self-biased CMOS inverter under the same resistive shunt feedback (the inverter resistive-feedback broadband LNA). The PMOS reuses the same current (gm_n + gm_p) and acts as the active load. There is no inductor, so the load can never turn inductive. R1 keeps the broadband real input match and sets Vg = Vd (self-bias at the trip point).
```netlist
C C1 VIN1 n1
R R1 n1 n2
NMOS NM1 n2 n1 VSS VSS
PMOS PM1 n2 n1 VDD VDD
C C2 n2 VOUT1
```
3. PREDICTION: mu_min_wide_0.01-50GHz improves from 0.71 to about 1.2 (about +0.5; it passes). The only feedback poles left are RC, so Re(Y_in) > 0 up to fT. Side effect: s21 should gain about 2-4 dB (roughly doubled gm at the same 9.3 mA), which closes the 12 dB gain gap. Ripple stays well below 1.6 dB across 1-2 GHz, and NF stays around 2 dB, inside the 3.7 dB cap.

==== ANSWER t2-nb090-noise-0240 ====
1. DIAGNOSIS
The binding failure is out-of-band stability (mu_wide = 0.79). In-band mu is also only 1.005, and s22 is poor at -4.4 dB, so the output is high-Q. The shared drain n2 drives a series L2-C2 branch to ground. Above that branch's series resonance, L2 makes the branch inductive. Between there and the parallel resonance with the drain capacitance, the drain load is therefore inductive and nearly lossless; the only loss is the device ro and the 50-ohm port behind C3. The NMOS and PMOS Cgd's (both gates are AC-tied to the input) feed this inductive load back to the gate. Their Miller admittance jwCgd(1 + gm*Z_L) then has a negative real part, and the input series inductor L1 resonates with Cgs and gives a voltage-boost Q, so the two-port is potentially unstable at multi-GHz frequencies. Nothing in the circuit damps the load at frequencies where L2 dominates.

2. EDIT: add a damping resistor R6 in parallel with L2 (n2 to n4). C2 still blocks DC, so the bias is unchanged. At high frequency the L2-C2 branch now tends toward a pure resistance to ground, a resistive HF termination. That caps the drain impedance, so it can no longer turn strongly inductive, and lowers the output Q. The sizer can keep R6 large enough to preserve most of the in-band tank impedance at 900 MHz.
```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n2 n1 VSS VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
R R6 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```
3. PREDICTION: mu_min_wide_0.01-50GHz improves from 0.79 to about 1.05 (+0.25; it just passes). In-band mu_min rises from about 1.00 to about 1.15, and s22 improves by about 3 dB. Cost: about 0.3-0.5 dB of s21, which the sizer recovers by retuning L2/C2.

==== ANSWER t2-wb1020-gain-0161 ====

The shared drain of the current-reuse pair is loaded by the series L2-C2 branch to ground. PMOS PM1 n2 n3 VDD VDD

==== ANSWER t2-nb090-noise-0129 ====
1. DIAGNOSIS
The binding failure is NF (2.46 vs 2.29 dB). Nothing in the circuit synthesizes a noiseless real input resistance: NM1 has its source grounded directly. The only resistive element at the gate node is the bias-feed resistor R2, which goes to the low-impedance mirror node. The 50-ohm match is therefore an L-match: series L1 against Cgs in parallel with R2. R2's thermal noise then appears directly at the gate, and the device's own noise is not optimally matched. That is a resistive-termination-like noise penalty, worth several tenths of a dB at 900 MHz. Every other metric is pinned at its gate (s11, s21, Idd, mu), so the sizer has no free variable to trade for lower NF.

2. EDIT: add an inductive source-degeneration inductor Ls (L3) between NM1's source and ground. Ls produces a noiseless real input term wT*Ls, so the 50-ohm real part comes from the device instead of R2. The sizer can then make R2 very large (bias feed only), and the device sits closer to its simultaneous noise/power match. Ls also adds series feedback, which raises the marginal mu.
```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n2 n1 n7 VSS
L L3 n7 VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```
3. PREDICTION: nf_db improves from 2.46 dB to about 1.9-2.0 dB (about 0.5 dB better; it passes the 2.29 dB gate). s11 stays at least as good as -8 dB, because the match now comes from wT*Ls. s21 drops by about 0.5 dB from degeneration, which the recovered input-resonance Q offsets. mu_min should rise slightly above its current marginal 1.00.
