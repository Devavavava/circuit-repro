==== ANSWER t2-nb090-noise-0143 ====
1. DIAGNOSIS
The binding failure is NF (2.54 vs 2.29 dB). NM1's source is grounded directly, so the input has no noiseless real part. The 50-ohm match is made as an L-match: series L1 resonating Cgs, with the real part supplied by the gate bias-feed resistor R2 (to the low-impedance mirror node). R2's thermal noise lands directly on the gate, and the device can't be placed at its optimum noise source impedance. That is a resistive-termination noise penalty. s11, s21, Idd and mu are all pinned at their gates, so the sizer has no freedom left to trade for NF.

2. EDIT: add an inductive source-degeneration inductor (L3) from NM1's source to ground. It creates a noiseless input real part wT*Ls, so the 50-ohm match no longer has to come from R2 (which the sizer can make large, as a pure bias feed). The input then approaches simultaneous noise and power match. The series feedback also helps the marginal stability.
```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n2 n1 n7 VSS
L L3 n7 VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```
3. PREDICTION: nf_db improves from 2.54 dB to about 2.0 dB (about 0.5 dB better; it passes 2.29 dB). s11 stays at -8 dB or better (match from wT*Ls). s21 is about 0.5 dB lower from degeneration, which the sizer compensates through the higher input-resonance Q. mu_min rises a little above 1.01.

==== ANSWER t2-wb1020-gain-0010 ====
1. DIAGNOSIS
The binding failure is wideband stability (mu_wide = 0.82). In-band mu is 1.21, so the problem is out of band. The shared drain of the NMOS/PMOS current-reuse pair has a series L2-C2 branch to ground. Above its series resonance the branch is inductive, so at multi-GHz frequencies the drain impedance is inductive and almost lossless. The combined Cgd of NM1 + PM1 (gates AC-tied via C1) couples this back to the input: Y_in = jwCgd(1 + gm*Z_L) gets a negative real part. The series gate inductor L1 resonating with Cgs adds voltage boost at the gate, so |S12*S21| exceeds the available loss margin and mu < 1. Nothing resistive damps the drain where L2 dominates.

2. EDIT: put a damping resistor R6 across L2 (n2 to n4). It is DC-isolated by C2, so the bias is unchanged. At high frequency the L2-C2 branch tends to R6 to ground, a resistive HF termination. That bounds the drain impedance, removes the inductive-load negative conductance, and lowers the output Q, which also helps s22 and ripple across 1-2 GHz.
```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n2 n1 VSS VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
R R6 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```
3. PREDICTION: mu_min_wide_0.01-50GHz improves from 0.82 to about 1.05-1.1 (+0.25; it passes). s22_max improves by about 2 dB. Peak s21 costs about 0.3 dB, which the sizer recovers by retuning L2/C2 within the Idd budget.

==== ANSWER t2-wb1020-gain-0207 ====
1. DIAGNOSIS
The binding failure is wideband stability, narrowly (mu_wide = 0.988). The output is high-Q (s22_max = -3.7 dB, delta_max = 0.32), and ripple is pinned at the gate. The current-reuse drain is loaded by a series L2-C2 branch to ground. Above that branch's series resonance it is inductive and almost lossless. The NM1 + PM1 Cgd (gates AC-tied via C1) then gives a Miller admittance jwCgd(1 + gm*Z_L) with a negative real part, and the series gate inductor L1 provides resonant gate-voltage gain. In that out-of-band window mu dips just below 1.

2. EDIT: add a damping resistor R6 across L2 (n2 to n4). The bias is unchanged (C2 blocks DC). At high frequency the branch becomes a resistive termination to ground, so the drain impedance can't turn strongly inductive, and the output Q drops. That improves both s22 and the in-band peaking that is setting the ripple.
```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n2 n1 VSS VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
R R6 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```
3. PREDICTION: mu_min_wide_0.01-50GHz improves from 0.99 to about 1.15 (+0.15; it passes). s22_max improves by about 2-3 dB, and ripple drops by about 0.2 dB. s21 costs about 0.2 dB, which the sizer recovers with the Idd margin (0.08 mA spare).

==== ANSWER t2-nb090-noise-0312 ====
1. DIAGNOSIS
The binding failure is the input match (s11 = -3.1 dB). The input DC block C1 goes straight to NM1's gate, so Zin at 900 MHz is essentially 1/(jwCgs) in parallel with the large bias-feed resistor R2. It is a high-Q capacitive impedance with almost no real part near 50 ohm. No element synthesizes a resistive input, and lowering R2 to provide one would wreck the 1.36 dB NF. The mismatch also wastes about 3 dB of transducer gain, and there is no input-resonance voltage gain. That largely explains s21 = 14.7 vs 18.65 dB.

2. EDIT: convert stage 1 to an inductively degenerated CS input: series gate inductor Lg (L4) after C1, and source-degeneration inductor Ls (L5) from NM1's source to ground. This gives Re(Zin) = wT*Ls = 50 ohm (noiseless), with Lg + Ls resonating Cgs at 900 MHz. To stay within the 4-inductor limit, the interstage series inductor L2 is removed. C2 couples the L1-tuned stage-1 drain directly into NM2's gate, and L1 absorbs Cgs2 into its resonance. The mirror bias is unchanged.
```netlist
C C1 VIN1 n0
L L4 n0 n1
NMOS NM1 n2 n1 n8 VSS
L L5 n8 VSS
L L1 VDD n2
C C2 n2 n5
NMOS NM2 n6 n5 VSS VSS
L L3 VDD n6
C C3 n6 VOUT1
R R1 VDD n7
NMOS NM3 n7 n7 VSS VSS
R R2 n7 n1
R R3 n7 n5
```
3. PREDICTION: s11_max_db improves from -3.1 dB to about -11 dB (about 8 dB better; it passes -7.85). Side effects: s21 rises by about 4-6 dB (mismatch loss recovered, plus the Q boost at the gate), NF stays about 1.3 dB, and mu_wide improves because the high-Q L2/Cgs2 series interstage resonance is gone.

==== ANSWER t2-nb090-noise-0254 ====
1. DIAGNOSIS
The binding failure is the input match (s11 = -3.0 dB). C1 connects straight to NM1's gate, so the input impedance is Cgs in parallel with a large bias resistor R2: almost purely capacitive at 900 MHz, with no real part near 50 ohm and |Gamma| close to 1. The NF budget (1.35 dB) forbids using a small R2 as the termination, so the sizer can't fix the match with the parts it has. The same mismatch, and the lack of input-resonance gate gain, keeps s21 at 14.6 vs 20.1 dB.

2. EDIT: make stage 1 an inductively degenerated CS: a series gate inductor (L4) after the DC block and a source inductor (L5) from NM1's source to ground. This gives a noiseless Re(Zin) = wT*Ls and resonant cancellation of Cgs. To respect the 4-inductor limit, the interstage series L2 is removed, and C2 couples stage 1 directly to NM2's gate, with L1 now resonating the stage-1 drain plus Cgs2. The mirror bias is unchanged.
```netlist
C C1 VIN1 n0
L L4 n0 n1
NMOS NM1 n2 n1 n8 VSS
L L5 n8 VSS
L L1 VDD n2
C C2 n2 n5
NMOS NM2 n6 n5 VSS VSS
L L3 VDD n6
C C3 n6 VOUT1
R R1 VDD n7
NMOS NM3 n7 n7 VSS VSS
R R2 n7 n1
R R3 n7 n5
```
3. PREDICTION: s11_max_db improves from -3.0 dB to about -11 dB (about 8 dB better; it passes). Side effects: s21 gains about 5 dB from the recovered mismatch loss plus the gate Q boost, NF stays about 1.3 dB, and mu_wide improves (no series L2/Cgs2 resonance, and Ls adds a positive input real part).

==== ANSWER t2-nb090-noise-0269 ====

The input is a DC-block cap straight into NM1's gate, so Zin is Cgs in parallel with the large bias-feed R2: strongly capacitive at 900 MHz, with no real part near 50 ohm. C C2 n2 n5

==== ANSWER t2-nb090-noise-0012 ====
1. DIAGNOSIS
The binding failure is wideband stability (mu over 0.01-50 GHz = 0.63); in-band mu is 1.29. The drain load is the shunt-peaking L1 in series with R2. Above the peaking zero, the load becomes inductive. With feedback through Cgd and through the shunt resistor R1, the input admittance jwCgd(1 + gm*jwL) gets a negative real part (-w^2*gm*L*Cgd) in the multi-GHz range, where the 45 nm NMOS still has gain, so mu < 1. Gain is pinned exactly at the 9.8 dB gate at the Idd cap: a single NMOS supplies all the gm, and the DC-drop resistor R2 loads the output. The sizer can't trade peaking for damping without losing gain.

2. EDIT: replace the shunt-peaked NMOS CS with a self-biased CMOS inverter (NM1 + PM1) inside the same R1 shunt feedback (the inverter resistive-feedback LNA). The PMOS reuses the bias current (gm_n + gm_p) and serves as the active load. With no inductor, the drain load is RC only and never turns inductive. R1 keeps Vg = Vd self-bias and the broadband real input match.
```netlist
C C1 VIN1 n1
R R1 n1 n2
NMOS NM1 n2 n1 VSS VSS
PMOS PM1 n2 n1 VDD VDD
C C2 n2 VOUT1
```
3. PREDICTION: mu_min_wide_0.01-50GHz improves from 0.63 to about 1.2 (about +0.55; it passes). Side effects: s21 gains about 2-4 dB of margin from the doubled gm at the same 6.1 mA, and NF stays about 1.6-1.8 dB (below the 1.79 gate, marginal).
