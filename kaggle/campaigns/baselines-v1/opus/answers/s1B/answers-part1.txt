==== ANSWER v2b-wb0824-gain-188 ====
1. DIAGNOSIS
The binding metric is nf_max_db, the worst-case NF across the 0.8-2.4 GHz band. The input match here is purely reactive and narrowband: a series gate inductor L1 resonates with the combined Cgs of NM1 and PM1 (PM1's gate is AC-tied through C1). That gives a good noise/power match only near f0 (nf_db 2.35 at f0). At the band edges the gate network detunes, so NF climbs to 2.50 dB and s11_max reaches -8.9 dB. The ripple numbers point the same way. A high-Q series resonance cannot cover a 3:1 band. The shunt bias resistor R2 (from the NM3 mirror) also adds noise directly at the gate. The out-of-band stability shortfall (mu_wide 0.90) comes from the same lossless, high-Q input network.

2. EDIT: turn it into a resistive-shunt-feedback, current-reuse inverter LNA. RF goes from the shared drain n2 to the NMOS gate n1. It gives a broadband real input resistance of about (RF+RL)/(1+gm_tot*RL), with gm_tot = gmn + gmp, and it self-biases the NMOS gate. That makes the NMOS mirror (R1/NM3/R2) and its gate-noise resistor unnecessary, so they are removed. L1 stays as a small series gate inductor to cancel Cgs at the top of the band (bandwidth extension). The PMOS gate keeps its published bias (PM2/R4/R5) and its AC coupling C1.

```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n2 n1 VSS VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
R RF n2 n1
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```

3. PREDICTION: nf_max_db improves (goes down) by about 0.4-0.5 dB, from 2.50 to about 2.0-2.1 dB. The flat, broadband match removes the band-edge NF peaking, and the R2 noise source is gone. s11_max improves by about 2-4 dB (to about -11 to -13 dB). The feedback loading also helps wideband stability: mu_wide rises to about 1.0-1.1.

==== ANSWER t2-wb1020-gain-0065 ====
1. DIAGNOSIS
Every in-band gate (NF, S11, S21, Idd) sits at the edge with near-zero margin. The worst failure is mu_min_wide over 0.01-50 GHz (0.886), while in-band mu (1.47) is fine. So the problem is potential instability out of band. The circuit is almost lossless away from f0:
- the series gate inductor L1 plus the Cgs of NM1/PM1 form a high-Q input resonance;
- the series L2-C2 trap at the shared drain adds a second high-Q resonance;
- the drain-gate capacitances of both devices give a reverse path through Cgd.
Far from f0 the input reflection gets close to 1 with nothing resistive to load it, so mu drops below 1. Nothing in the topology adds broadband loss at either port.

2. EDIT: add a broadband resistive shunt-feedback path from the shared drain to the NMOS gate, DC-blocked by CF so the published gate bias networks keep working unchanged. The feedback resistor makes both ports lossy at every frequency, lowers the out-of-band |S11| and |S22| peaks and the loop gain, and also broadens the in-band match.

```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n2 n1 VSS VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
R RF n2 n7
C CF n7 n1
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```

3. PREDICTION: mu_min_wide_0.01-50GHz improves by about +0.15 to +0.25, from 0.886 to about 1.05-1.1, which would pass. Expected side effects: S21 drops about 0.5 dB at fixed current, which the sizer can win back with gm; s11_max improves by 1-3 dB; NF stays roughly flat (+/-0.1 dB).

==== ANSWER t2-wb1020-gain-0088 ====
1. DIAGNOSIS
The worst failure is mu_min_wide over 0.01-50 GHz (0.716), and s21 is also about 2.4 dB short (9.26 vs 11.64 dB) at the Idd cap. The load is a series L1+R2 shunt-peaking branch, so at high frequency the drain load becomes inductive. With an inductive drain load, the Miller admittance through Cgd, jwCgd(1+gm*ZL), has a negative real part, so the gate sees negative input conductance well above the band. This is the classic instability of a CS stage with an inductive load. The sizer had to keep gm*R small to hold this down, which is why S21 is short. A single NMOS also gives only gm_n of transconductance per mA within the 7.6 mA budget.

2. EDIT: replace the inductive shunt-peaked load with a PMOS current-reuse device driven by the same gate. This is the resistive-feedback CMOS inverter LNA. RF still self-biases both gates and sets a broadband 50-ohm match. Transconductance becomes gmn+gmp at the same current, about 1.7-2x, so gain rises. There is no inductor in the drain load, so the negative-conductance mechanism is removed at every frequency.

```netlist
C C1 VIN1 n1
R R1 n1 n2
NMOS NM1 n2 n1 VSS VSS
PMOS PM1 n2 n1 VDD VDD
C C2 n2 VOUT1
```

3. PREDICTION: mu_min_wide improves by about +0.3 to +0.4, from 0.72 to about 1.05-1.2 (a resistive-feedback inverter is unconditionally stable or close to it). S21 improves by about +2.5-3.5 dB, to about 12 dB, at the same 7.6 mA. NF stays well inside its 3.48 dB cap (about 1.5-2.0 dB).

==== ANSWER t2-wb1020-gain-0043 ====
1. DIAGNOSIS
The worst failure is mu_min_wide (0.641) out of band. In-band k and mu are only about 1.1-1.2, delta is large (0.34-0.38), and S21 is about 0.5 dB short at the Idd cap.
```netlist
C C1 VIN1 n1
R R1 n1 n2
NMOS NM1 n2 n1 VSS VSS
PMOS PM1 n2 n1 VDD VDD
C C2 n2 VOUT1
```

3. PREDICTION: mu_min_wide improves by about +0.4, from 0.64 to about 1.05-1.2. S21 improves by about +2-3 dB, to about 13 dB, at an Idd of 11 mA or less. NF stays about 1.5-2.0 dB, well inside the 3.9 dB cap.

==== ANSWER t2-nb090-noise-0286 ====
1. DIAGNOSIS
The binding metric is s11_max_db at -3.7 dB. Stage 1 has no input-matching network: C1 couples VIN1 straight onto the NM1 gate, so the 900 MHz input impedance is basically 1/(jwCgs) in parallel with the bias resistor R2. That is highly reactive with almost no real part, so the source is badly mismatched whatever the sizing. The same mismatch costs stage-1 gain: S21 is 13.8 vs 19.4 dB needed, because there is no series-resonant Q voltage boost at the gate. NF only meets 1.5 dB because the sizer traded match for noise. The interstage series L2 does far less than an input-match inductor would.

2. EDIT: use the classic inductively degenerated input. Add a series gate inductor LG (the inductor previously used as the interstage series L2 moves to the input) and a source-degeneration inductor LS on NM1. This gives Re(Zin) = wT*LS, set to 50 ohm, with LG+LS resonating Cgs at 900 MHz. The interstage becomes a plain DC-blocking C2 into NM2, with L1 as the tuned load. The inductor count stays at 4 (LG, LS, L1, L3), within the screen.

```netlist
C C1 VIN1 n0
L LG n0 n1
NMOS NM1 n2 n1 n8 VSS
L LS n8 VSS
L L1 VDD n2
C C2 n2 n5
NMOS NM2 n6 n5 VSS VSS
L L3 VDD n6
C C3 n6 VOUT1
R R1 VDD n7
NMOS NM3 n7 n7 VSS VSS
R R2 n7 n1
R R3 n7 n5
```

3. PREDICTION: s11_max_db improves by about 8-10 dB, from -3.7 to about -12 to -14 dB at 900 MHz. S21 also improves by about +5 dB (the input-network Q boost raises the effective gm of stage 1), to about 19-20 dB. NF stays about 1.3-1.5 dB, because the input network is noise-and-power matched simultaneously.

==== ANSWER t2-wb1020-gain-0046 ====

Both stability metrics fail. In-band mu is 0.888, k is only 0.29, and the out-of-band mu_wide is 0.885. The decisive clue is s22 of -0.24 dB (max -0.04 dB): the output port is almost lossless and fully reflective.
