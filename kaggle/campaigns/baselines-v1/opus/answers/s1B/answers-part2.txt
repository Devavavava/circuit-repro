==== ANSWER t2-nb090-noise-0323 ====
1. DIAGNOSIS
The binding metric is s11_max_db at -4.2 dB. Stage 1 has no input-matching network: VIN1 reaches the NM1 gate only through the DC block C1. At 900 MHz the input therefore looks like the gate capacitance Cgs in parallel with the bias-feed resistor R2. That impedance is mostly reactive, and its small real part comes only from R2 and the gate resistance. No sizing of NM1 can make it look like 50 ohm, and widening NM1 only makes the input more capacitive. The sizer is also pinned on NF and Idd. The interstage series L2 cannot help the input port.

2. EDIT: convert stage 1 to the classic inductively source-degenerated CS input. Add a series gate inductor LG and a source inductor LS on NM1. The real part is then Re(Zin) = wT*LS, set to 50 ohm, and LG+LS series-resonate Cgs at 900 MHz. This also gives simultaneous noise and power match. To stay within the 4-inductor screen, the interstage series L2 is dropped: C2 now couples straight to the NM2 gate, and L1 stays as the tuned load. Inductors are LG, LS, L1, L3.

```netlist
C C1 VIN1 n0
L LG n0 n1
NMOS NM1 n2 n1 n8 VSS
L LS n8 VSS
L L1 VDD n2
C C2 n2 n5
NMOS NM2 n6 n5 VSS VSS
L L3 VDD n6
C C3 n6 VOUT1
R R1 VDD n7
NMOS NM3 n7 n7 VSS VSS
R R2 n7 n1
R R3 n7 n5
```

3. PREDICTION: s11_max_db improves by about 7-9 dB, from -4.2 to about -11 to -13 dB across 882-918 MHz. S21 also rises by about 3-5 dB from the gate-voltage Q boost. NF stays at about 1.6-1.8 dB, inside the 1.85 dB cap.

==== ANSWER t2-wb1020-gain-0107 ====
1. DIAGNOSIS
The worst failure is mu_min_wide over 0.01-50 GHz (0.714), and S21 is also about 1.5 dB short at the Idd cap. The CS device drives a shunt-peaked load, L1 in series with R2, which becomes inductive above the band. Through Cgd, an inductive drain load produces a negative real part in the gate admittance: Re{jwCgd*gm*ZL} < 0 when ZL is inductive. The input therefore has negative conductance well above the band, damped only by the feedback resistor R1. With one NMOS supplying all the transconductance, gm*R_load cannot rise without worsening this, so gain and stability are traded against each other.

2. EDIT: convert the circuit to a resistive-feedback CMOS inverter (current-reuse) LNA. A PMOS driven from the same gate node replaces L1/R2 and carries the same DC current. Removing the inductive load removes the negative-conductance mechanism. The transconductance becomes gmn+gmp at unchanged Idd, about 1.7-2x, which also closes the gain gap. R1 continues to self-bias both gates and set the broadband input match.

```netlist
C C1 VIN1 n1
R R1 n1 n2
NMOS NM1 n2 n1 VSS VSS
PMOS PM1 n2 n1 VDD VDD
C C2 n2 VOUT1
```

3. PREDICTION: mu_min_wide improves by about +0.3 to +0.4, from 0.71 to about 1.05-1.2. S21 improves by about +2-3 dB, to about 11.5-12 dB. NF stays at about 1.5-2.0 dB, well inside the 3.46 dB cap.

==== ANSWER t2-wb1020-gain-0160 ====

==== ANSWER t2-wb1020-gain-0184 ====
1. DIAGNOSIS
The binding metric is s21_db: 10.4 dB against a 12.6 dB minimum. The single current-reuse stage gets its gain as (gmn+gmp) times the drain node impedance, but that node is the low intrinsic ro_n||ro_p of short-channel 45 nm devices in parallel with the 50-ohm load (s22 is already -9.5 dB, so the drain impedance is close to 50 ohm). At 6.8 mA total, gm is fixed by the Idd cap. In a 1-2 GHz band, the input L1-Cgs network cannot add much passive voltage gain without breaking ripple and match. NF and s11 are also at their limits, so the sizer has no slack left. One gain stage driving 50 ohm directly cannot reach 12.6 dB inside this current.

2. EDIT: build a two-stage stacked current-reuse amplifier, so the same DC current is used twice for gain. Stage 1 (NM1, published mirror bias, L1 input) drives inductor LD. LD runs to the source node n8 of a stacked second NMOS stage, NM2, and n8 is AC-grounded by CB. NM2's gate is AC-coupled from n2 through CC and self-biased by RF2 from its drain. RF2 is also a resistive shunt feedback around stage 2, which gives a broadband, low output impedance. The stage-2 load is LO to VDD, and the output is DC-blocked by C3. The PMOS path and the L2-C2 trap are removed. Inductors are L1, LD, LO: 3 in total.

```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n2 n1 VSS VSS
L LD n8 n2
C CB n8 VSS
C CC n2 n10
NMOS NM2 n9 n10 n8 VSS
R RF2 n9 n10
L LO VDD n9
C C3 n9 VOUT1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
```

3. PREDICTION: s21_db improves by about 3-5 dB, from 10.4 to about 13.5-15 dB at the same 6.8 mA, because two cascaded gm stages share one current. The RF2 feedback keeps ripple within about 0.4 dB. NF changes by +0.2 dB at most, because stage 1 now uses only NMOS gm and stage 2's noise is suppressed by stage-1 gain. mu_wide improves because RF2 makes the output port lossy.
