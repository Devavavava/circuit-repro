==== ANSWER t2-wb1020-gain-0142 ====
1. DIAGNOSIS
The worst failure is mu_min_wide at 0.895. In-band mu and k sit exactly at 1.000 and S21 is 0.2 dB short, so the sizer is pressing gain directly against the stability boundary. The current-reuse stage has a narrowband, high-Q series L1-Cgs input (s11 is -12.6 dB at f0 but -7.9 dB at the edges). Its output is a high-impedance shared drain with only the reactive L2-C2 trap (s22_max -3.2 dB). Cgd of both devices provides reverse transmission into these nearly lossless terminations. Any increase in gm (for S21) therefore pushes mu further below 1, both out of band and at the band edges. The topology has no broadband dissipative element to decouple gain from stability.

2. EDIT: add DC-blocked resistive shunt feedback RF-CF from the shared drain n2 to the NMOS gate n1. It provides broadband loss at both ports, lowers the output impedance, and de-Qs the input, so k and mu rise at every frequency. The sizer can then raise gm toward the S21 target without hitting the stability wall. The published bias networks are unchanged.

```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n2 n1 VSS VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
R RF n2 n7
C CF n7 n1
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```

3. PREDICTION: mu_min_wide improves by about +0.15 to +0.2, from 0.895 to about 1.05-1.1, and in-band mu_min rises to about 1.15-1.2. At fixed bias S21 falls about 0.3-0.5 dB, but the new stability headroom lets the sizer recover it toward 13.6 dB. s22_max improves by about 4 dB.

==== ANSWER t2-nb090-noise-0322 ====
1. DIAGNOSIS
The binding metric is s11_max_db at -3.1 dB. NM1's gate is driven straight through the DC block C1 with no matching network, so the 900 MHz input is Cgs in parallel with the R2 bias feed. That is mostly capacitive, and the circuit cannot produce a 50-ohm real part. With NF pinned at its 1.34 dB cap, the sizer used a large R2 and a wide NM1, which makes the input even more reactive. With no input resonance there is no gate-voltage Q boost, so S21 is also 4 dB short.

2. EDIT: use an inductively source-degenerated input stage. Add a series gate inductor LG and a source-degeneration inductor LS on NM1, giving Re(Zin) = wT*LS = 50 ohm, with LG+LS resonating Cgs at 900 MHz. This gives simultaneous noise and power match plus a Q voltage gain at the gate. The interstage series L2 is removed, with C2 coupling straight to the NM2 gate, keeping 4 inductors (LG, LS, L1, L3).

```netlist
C C1 VIN1 n0
L LG n0 n1
NMOS NM1 n2 n1 n8 VSS
L LS n8 VSS
L L1 VDD n2
C C2 n2 n5
NMOS NM2 n6 n5 VSS VSS
L L3 VDD n6
C C3 n6 VOUT1
R R1 VDD n7
NMOS NM3 n7 n7 VSS VSS
R R2 n7 n1
R R3 n7 n5
```

3. PREDICTION: s11_max_db improves by about 8-10 dB, from -3.1 to about -11 to -13 dB. S21 improves by about 4 dB, to about 18.5-19 dB. NF stays at about 1.2-1.4 dB.

==== ANSWER t2-wb1020-gain-0182 ====
1. DIAGNOSIS
The worst failure is mu_min_wide at 0.709, and in-band k and mu are only about 1.14-1.19. The CS NMOS drives the shunt-peaked series L1+R2 load, which becomes inductive above the band. An inductive drain load seen through Cgd puts a negative real part into the gate admittance (Miller term jwCgd*gm*jwL), so the input shows negative conductance at multi-GHz. The feedback resistor R1 is the only damping. S21 is also about 0.4 dB short at the Idd cap, because only the NMOS supplies gm.

2. EDIT: convert the circuit to a resistive-feedback current-reuse CMOS inverter LNA. A PMOS driven from the same gate and carrying the same DC current replaces the inductive L1/R2 load. This removes the negative-conductance mechanism and roughly doubles gm per mA. R1 still self-biases both gates and sets the broadband 50-ohm match.

```netlist
C C1 VIN1 n1
R R1 n1 n2
NMOS NM1 n2 n1 VSS VSS
PMOS PM1 n2 n1 VDD VDD
C C2 n2 VOUT1
```

3. PREDICTION: mu_min_wide improves by about +0.35, from 0.71 to about 1.05-1.2. S21 improves by about +2-3 dB, to about 12 dB. NF stays at about 1.5-2.0 dB, inside the 4.58 dB cap.
