==== ANSWER t2-nb090-noise-0013 ====
1. DIAGNOSIS
mu_min_wide is 0.92, and in band mu and k are only about 1.03.
In the push-pull core the summed NMOS and PMOS Cgd give S12 of only -25.6 dB. Both terminations are reactive:
- the gate is fed through the series inductor L1, so its source impedance is inductive;
- the drain sees the L2+C2 branch, which is inductive above its series resonance.
This TITO coupling makes a negative-resistance region away from 900 MHz. The output is nearly reflective (s22 -4.5 dB), so there is no broadband loss to damp it. NF and gain are at zero margin.

2. EDIT: RC shunt feedback from drain to NMOS gate
Add RF plus a DC-block CF from n2 to n1. This provides broadband resistive damping of both ports and a better s22, and leaves the bias unchanged. s11 has slack (0.18) to absorb the change in Rin.

```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n2 n1 VSS VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R RF n2 n8
C CF n8 n1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```

3. PREDICTION
mu_min_wide improves from 0.92 to about 1.08 (+0.15).
Secondary effects:
- In-band mu rises to about 1.2.
- s22 improves by about 3 dB.
- s21 drops by about 0.3 dB.
- NF rises by about 0.05 dB.
The sizer can recover the last two with a large RF.

==== ANSWER t2-wb1020-gain-0001 ====
1. DIAGNOSIS
mu_min_wide is 0.64. The shunt-peaking inductor L1 makes the drain load inductive at high frequency, and through Cgd (Miller) that reflects a negative resistance onto the gate. The input is therefore active out of band.
Gain is also 0.35 dB short at the 9.8 mA cap. A single NMOS with a feedback match is limited by gm per mA.

2. EDIT: CMOS inverter (current-reuse) resistive-feedback LNA
Replace L1+R2 with a PMOS whose gate is shared with the NMOS gate, self-biased through R1. The load becomes purely resistive, and gm doubles at the same Idd.

```netlist
C C1 VIN1 n1
R R1 n1 n2
NMOS NM1 n2 n1 VSS VSS
PMOS PM1 n2 n1 VDD VDD
C C2 n2 VOUT1
```

3. PREDICTION
mu_min_wide improves from 0.64 to about 1.1 (+0.45).
Secondary effects:
- s21 rises by about 3 dB.
- NF stays around 2 dB.

==== ANSWER t2-wb1020-gain-0028 ====
1. DIAGNOSIS
NF_max is 2.16 dB against a 1.97 dB cap, and s11_max is -7.26 dB, also failing at the band edges.
The input is a series L1 resonating with the summed Cgs, but the circuit has no noiseless real input resistance. The real part comes from the bias feed resistors (R2 on the NMOS gate, R5 coupled in through C1) and other losses. That resistive termination puts its noise directly at the input, and because the real part is set by fixed resistors rather than a broadband mechanism, the match also falls off across 1-2 GHz.

2. EDIT: inductive source degeneration on NM1
Add LS from the NM1 source to VSS. This gives a noiseless, roughly frequency-independent real input resistance of about omega_T*LS. The bias resistors can then become large. The added series feedback also lowers the input Q, which flattens s11 across the octave.

```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n2 n1 n8 VSS
L LS n8 VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```

3. PREDICTION
NF_max improves from 2.16 dB to about 1.85-1.9 dB (about 0.25 to 0.3 dB better).
Secondary effects:
- s11_max improves from -7.3 dB to about -9 dB.
- mu_min_wide rises slightly, to about 1.0 or above.
