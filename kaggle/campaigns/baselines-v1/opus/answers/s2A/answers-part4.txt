==== ANSWER t2-nb090-noise-0240 ====
1. DIAGNOSIS
mu_min_wide is 0.79, and in band mu is only about 1.005.
In the push-pull core the summed NMOS and PMOS Cgd give S12 of only -26 dB. Both terminations are reactive:
- the gate is fed through the series inductor L1, so its source impedance is inductive;
- the drain sees L2+C2, which is inductive above its series resonance.
This TITO coupling gives a negative-resistance region away from 900 MHz. The output is almost reflective (s22 -4.4 dB) with no resistive damping. Gain is short by 0.45 dB, so the sizer cannot trade gain for stability.

2. EDIT: RC shunt feedback from drain to NMOS gate
Add RF plus a DC-block CF from n2 to n1. This provides broadband resistive damping of both ports and leaves the bias unchanged. NF (margin +0.02) and s11 (margin +0.10) have some slack to absorb it.

```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n2 n1 VSS VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R RF n2 n8
C CF n8 n1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```

3. PREDICTION
mu_min_wide improves from 0.79 to about 1.05 (+0.25).
Secondary effects:
- In-band mu rises to about 1.2.
- s22 improves by about 3 dB.
- NF rises by about 0.05 to 0.1 dB.

==== ANSWER t2-nb090-noise-0350 ====
1. DIAGNOSIS
s11_max_db is -2.3 dB. The first stage is a bare common-source gate driven through a DC block, so its input is capacitive (Cgs plus the Miller Cgd). The only real part is the bias feed R2, which the 1.146 dB NF cap forbids reducing.
The unmatched gate also gives up voltage gain, so s21 is 7.9 dB short (15.0 vs 22.8 dB).
mu_min_wide is 0.83 because stage 2 is a TITO configuration (series inductor L2 on its gate, L3 tank on its drain, coupled through Cgd).

2. EDIT: series gate inductor plus inductive source degeneration on NM1, common-gate cascodes on both stages, interstage series L removed
This keeps 4 inductors. The edit gives a noiseless 50-ohm real input at resonance, Q-boosted gate voltage gain, and Cgd isolation.

```netlist
C C1 VIN1 n0
L LG n0 n1
NMOS NM1 n8 n1 n9 VSS
L LS n9 VSS
NMOS NM4 n2 VDD n8 VSS
L L1 VDD n2
C C2 n2 n5
NMOS NM2 n10 n5 VSS VSS
NMOS NM5 n6 VDD n10 VSS
L L3 VDD n6
C C3 n6 VOUT1
R R1 VDD n7
NMOS NM3 n7 n7 VSS VSS
R R2 n7 n1
R R3 n7 n5
```

3. PREDICTION
s11_max_db improves from -2.3 dB to about -10 dB (about 7 to 8 dB better).
Secondary effects:
- s21 rises by about 5 to 7 dB.
- mu_min_wide rises above 1.
- NF stays roughly flat.

==== ANSWER v2b-wb1020-noise-217 ====
1. DIAGNOSIS
s11_max_db is -6.8 dB, failing at the band edges.
The circuit is also potentially unstable in band: mu_min is 0.79 and k is 0.25, and s22 is -1 dB, so the output is essentially lossless and reflective. The match is a narrowband series L1-Cgs resonance (-10.3 dB at center), which cannot cover the 1-2 GHz octave.
The drain sees only reactive loading (the ro's plus the L2+C2 branch), so the summed-Cgd feedback (S12 -24 dB) with an inductive gate termination makes the device nearly oscillatory. That near-oscillation also distorts the input impedance at the band edges.
There is no broadband resistive mechanism to set either port.

2. EDIT: RC shunt feedback from drain to NMOS gate
Add RF plus a DC-block CF from n2 to n1. Resistive shunt feedback:
- sets broadband real input and output impedances, roughly (RF+RL)/(1+gm*RL) at the input;
- de-Qs the series-L1 match;
- adds a positive conductance at both ports, restoring unconditional stability.
The bias is unchanged.

```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n2 n1 VSS VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R RF n2 n8
C CF n8 n1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```

3. PREDICTION
s11_max_db improves from -6.8 dB to about -10 dB (about 3 dB better).
Secondary effects:
- mu_min rises from 0.79 to about 1.1.
- s22 improves from -1 dB to about -8 dB.
- NF rises by about 0.1 dB, which is the main risk for the 1.70 dB cap.
