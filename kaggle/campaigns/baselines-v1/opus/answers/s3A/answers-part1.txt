==== ANSWER t2-nb090-noise-0012 ====
1. DIAGNOSIS
Every in-band spec passes (NF, S11, S21, Idd, in-band mu = 1.29). The failure is wideband: mu over 0.01-50 GHz drops to 0.63, so somewhere out of band, well above f0, the circuit is potentially unstable. The cause is the shunt-peaked drain load. L1 is in series with R2, so above the peaking frequency the drain impedance becomes strongly inductive (Z_L ~ jwL1) and stays that way until L1 self-resonates with the drain capacitance. When a common-source stage has an inductive load, its Cgd turns into a negative conductance at the gate: Y_in,Cgd = jwCgd(1 + gm*jwL1) = jwCgd - w^2*gm*Cgd*L1. The resistive feedback R1 only adds a fixed 1/R1 of positive conductance. At high frequency the w^2 term outgrows it, so some passive source or load termination can make the input or output port reflection exceed 1. The load inductor has nothing in parallel to bound its high-frequency impedance (no de-Q). That missing damping is what limits mu out of band.

2. EDIT: put a de-Q resistor R3 in parallel with L1. In band, R3 can be large enough that the peaking at 0.9 GHz is kept. At high frequency the drain impedance is then capped near R3+R2 (resistive) instead of rising inductively. This removes the w^2*gm*Cgd*L term that produces the negative gate conductance, and it also damps the L1/Cdb self-resonance. The DC path is unchanged.
```netlist
C C1 VIN1 n1
R R1 n1 n2
NMOS NM1 n2 n1 VSS VSS
L L1 VDD n3
R R3 VDD n3
R R2 n3 n2
C C2 n2 VOUT1
```
3. PREDICTION: mu_min_wide_0.01-50GHz improves from 0.63 to about 1.05 (+0.4). In-band mu_min stays above 1.2. S21 at 0.9 GHz drops by 0.3 dB or less, and NF rises by less than 0.1 dB.

==== ANSWER t2-wb1020-gain-0223 ====
1. DIAGNOSIS
The binding constraint is out-of-band stability: mu over 0.01-50 GHz is 0.65, while in-band mu is 1.14. S21 is also 0.6 dB short (9.56 vs 10.15 dB) with Idd pinned at its cap. The two failures are coupled. The single common-source device drives an inductive shunt-peaked load (L1 in series with R2) directly, so its Cgd couples that inductive drain back to the gate. Every attempt by the optimizer to raise gain (more gm*Z_L) makes mu worse, so the sizer is stuck between gain and wideband stability. Low intrinsic gain (gm*ro) in a short-channel device at this current also caps the gain.

2. EDIT: cascode the gain device. NM2 is a common-gate device with its gate on VDD (AC ground). The input device's Cgd now sees only the low, resistive 1/gm2 impedance at the cascode node instead of the inductive load. NM2's own Cgd goes to an AC-grounded gate, so the inductive-load-to-gate Miller path is removed. The loop through R1 feeds back only a resistive conductance. The cascode also raises output resistance, which helps S21. The self-bias (gate DC = output DC through R1) is kept.
```netlist
C C1 VIN1 n1
R R1 n1 n2
NMOS NM1 nc n1 VSS VSS
NMOS NM2 n2 VDD nc VSS
L L1 VDD n3
R R2 n3 n2
C C2 n2 VOUT1
```
3. PREDICTION: mu_min_wide_0.01-50GHz improves from 0.65 to about 1.1 (+0.45). With the stability constraint released, S21 rises by about 0.5-1 dB, which reaches the 10.15 dB gate.

==== ANSWER t2-wb1020-gain-0089 ====
1. DIAGNOSIS
The circuit is very close: wideband mu is 0.954 (margin -0.046), and NF, S21 and Idd are all pinned at their limits. This is a current-reuse inverter with no resistive damping in the signal path. The input is a series gate inductor L1 into a purely capacitive gate (Cgs,n + Cgs,p via C1). The output is a high-Q inductive tank (L2 to ground through DC-block C2) in parallel with ro_n||ro_p. Both Cgd's couple that inductive output back to the gate, giving a negative gate conductance of about -w^2*(gm_n+gm_p)*Cgd*L2. The gate inductor L1 and Cgs form a high-Q series resonance that can resonate against that negative conductance. With no lossy element bridging input and output, mu dips just below 1 out of band (and the poor S22 of -3.3 dB worst-case shows the output is almost lossless/reactive).

2. EDIT: a shunt-shunt RC feedback network from output to the gate node: Rf in series with DC-block Cf. Because the feedback is resistive, it adds a positive real conductance to both ports and gives a lossy reverse path in place of the purely capacitive Cgd one. That damps both the L1-Cgs resonance and the output tank. It also gives broadband real input and output matching (S22 improves). Cf keeps the existing gate bias networks untouched. With a large Rf, the gain and NF penalties are small.
```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n2 n1 VSS VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R Rf n2 nf
C Cf nf n1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```
3. PREDICTION: mu_min_wide_0.01-50GHz improves from 0.954 to about 1.1-1.2 (+0.15 to +0.25). S11 and S22 improve by about 2-3 dB. S21 falls by about 0.5 dB at fixed sizing (with Rf of several hundred ohms), which the optimizer has to win back through device sizing. NF rises by about 0.1 dB.

==== ANSWER t2-nb090-noise-0411 ====
1. DIAGNOSIS
The binding failure is the input match: S11 is -1.85 dB, nearly total reflection. The input of stage 1 is a DC-block (C1) straight onto the NM1 gate, with only a high-value bias feed resistor (R2) at that node. The input impedance is therefore essentially 1/(jw*Cgs) in parallel with the large R2. It is almost purely reactive (several hundred ohms at 0.9 GHz) and has no 50-ohm real part, so no sizing can match it. The mismatch also wastes the input signal, which is why S21 is 7 dB short (14.8 vs 21.8 dB). NF only passes because of the "series_rs" noise-matched evaluation, not because of a power match. The two inductors used in the original published form, a gate inductor Lg and a source-degeneration inductor Ls, were trimmed out. Their job is to create Re{Zin} = wT*Ls = 50 ohm noiselessly and to resonate out Cgs.

2. EDIT: convert stage 1 to an inductively degenerated CS. Add Lg in series with the gate after C1 and Ls from the NM1 source to ground. To stay within the 4-inductor screen, the interstage series inductor L2 is removed: the stage-2 gate is driven by DC-block C2 directly from the L1-tuned drain, which is still a tuned interstage. Bias is kept: R2 feeds the NM1 gate and R3 feeds the NM2 gate.
```netlist
C C1 VIN1 n0
L Lg n0 n1
NMOS NM1 n2 n1 ns VSS
L Ls ns VSS
L L1 VDD n2
C C2 n2 n5
NMOS NM2 n6 n5 VSS VSS
L L3 VDD n6
C C3 n6 VOUT1
R R1 VDD n7
NMOS NM3 n7 n7 VSS VSS
R R2 n7 n1
R R3 n7 n5
```
3. PREDICTION: S11_max improves from -1.85 dB to about -10 to -12 dB (an improvement of about 9 dB). The Lg-Ls series resonance also gives Q-boosted gain, so S21 rises by about 5-7 dB (toward 20-22 dB). Ls degeneration also adds margin to wideband mu. NF stays at about 1.0-1.2 dB.

==== ANSWER t2-nb090-noise-0240 ====
1. DIAGNOSIS
The binding constraint is wideband stability (mu over 0.01-50 GHz is 0.79), and even in band the circuit is marginal (mu_min 1.005, k about 1.01). The output of the current-reuse inverter is loaded only by ro_n||ro_p and an inductive shunt tank (L2 to ground via DC-block C2). That tank is high-Q and lossless, which the poor S22 of -4.4 dB confirms. Below and around its resonance the drain impedance is inductive. Through both Cgd's, this makes a negative conductance at the gate (about -w^2*(gm_n+gm_p)*Cgd*L2). The series gate inductor L1 resonating with Cgs then presents a high-Q, low-loss input that this negative conductance can overcome. Nothing resistive limits the Q of the output tank, so mu falls below 1 off band.

2. EDIT: add a de-Q resistor R6 in parallel with the output tank inductor L2. Through DC-block C2 it becomes a lossy shunt at the output. In band, R6 can be chosen large so the tank still provides gain. Out of band the output impedance is bounded and resistive, which removes the large inductive impedance that drives the negative Miller conductance. It also improves S22. DC bias paths are unchanged, because C2 still blocks DC.
```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n2 n1 VSS VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
R R6 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD

```
