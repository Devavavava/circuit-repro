==== ANSWER v2b-wb1020-noise-217 ====
1. DIAGNOSIS
The binding constraint is the broadband input match: worst-case S11 is -6.8 dB against a -9.0 dB gate, although S11 at f0 is -10.3 dB. The circuit is also unstable in band: mu_min is 0.79 and k is about 0.27. The input network is a narrowband series resonance, L1 in series with the capacitive inverter gate (Cgs,n plus Cgs,p via C1). Its real part comes only from the bias-feed resistors and the Cgd/Miller terms. It can therefore be matched near one frequency, but S11 degrades quickly toward 1 and 2 GHz, the edges of the octave band. The output is an almost lossless inductive tank (L2 to ground via C2) in parallel with ro_n||ro_p; S22 is about -0.7 dB, meaning almost total reflection. Feeding this high-Q inductive output back through both Cgd's produces a negative input conductance, which shows up as mu < 1 and also distorts the input reflection. Nothing in the topology gives a broadband, resistive, real input impedance.

2. EDIT: resistive shunt-shunt feedback from output to input. Rf in series with DC-block Cf goes from the shared drain n2 to the gate node n1. It sets a broadband real input resistance of about (Rf + Z_L)/(1 + gm_total*Z_L), largely independent of frequency, so the input match flattens across 1-2 GHz. It also adds positive real conductance at both ports (stabilizing and improving S22) and flattens the gain. Cf leaves the published gate bias networks unchanged.
```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n2 n1 VSS VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R Rf n2 nf
C Cf nf n1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```
3. PREDICTION: S11_max improves from -6.8 dB to about -10 dB (+3 dB). mu_min rises above 1 (to about 1.1). S21 falls by about 0.5 dB at fixed sizing. NF rises by about 0.1-0.2 dB, so NF stays marginal.

==== ANSWER t2-wb1020-gain-0066 ====
1. DIAGNOSIS
The binding constraint is out-of-band stability, and only by a hair: mu over 0.01-50 GHz is 0.982, while in-band mu is 1.32. NF, S11, S21 and Idd are all pinned at their gates, so the fix has to be nearly free in band. The cause is the high-Q output tank of the current-reuse inverter: L2 to ground through C2, in parallel with ro_n||ro_p and with no resistive loss (S22_max is -5.2 dB). Where that load is inductive, the Cgd's of NM1 and PM1 reflect it as a negative conductance at the gate, about -w^2*(gm_n+gm_p)*Cgd*L2. Together with the series-resonant gate inductor L1, this pushes mu just below 1 off band.

2. EDIT: put a de-Q resistor R6 in parallel with the output tank inductor L2. Out of band, the output branch becomes a bounded, resistive impedance (R6 through C2), which removes the inductive drive behind the negative Miller conductance and damps the L2 resonance. In band, R6 can be large, and since its noise is referred through the full stage gain, the cost to NF and S21 is negligible. C2 keeps it off the DC path.
```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n2 n1 VSS VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
R R6 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```
3. PREDICTION: mu_min_wide_0.01-50GHz improves from 0.98 to about 1.1 (+0.1 to +0.15). S21 falls by 0.2 dB or less at fixed sizing, and NF rises by about 0.02 dB or less. S22 improves by about 2 dB.

==== ANSWER t2-nb090-noise-0287 ====
1. DIAGNOSIS
The binding constraint is the input match: S11 is -4.9 dB against a -7.85 dB gate. Stage 1 is a CS device whose gate is reached only through the DC-block C1, and the only other element at that node is the high-value bias-feed resistor R2. The input impedance is therefore essentially 1/(jw*Cgs) in parallel with R2: mostly reactive, with no controlled 50-ohm real part. The optimizer can only trade NF against a lossy, poor match, and both NF and S21 sit at their gates. The textbook noiseless matching elements, a gate inductor (to resonate out Cgs) and a source-degeneration inductor (Re{Zin} = wT*Ls), are missing. Wideband mu is also below 1 (0.85).

2. EDIT: an inductively degenerated first stage. Lg goes in series with the gate after C1, and Ls goes from the NM1 source to ground. To respect the 4-inductor screen, the interstage series inductor L2 is dropped: C2 couples the L1-tuned drain straight to the NM2 gate. Biasing through R2 and R3 is unchanged.
```netlist
C C1 VIN1 n0
L Lg n0 n1
NMOS NM1 n2 n1 ns VSS
L Ls ns VSS
L L1 VDD n2
C C2 n2 n5
NMOS NM2 n6 n5 VSS VSS
L L3 VDD n6
C C3 n6 VOUT1
R R1 VDD n7
NMOS NM3 n7 n7 VSS VSS
R R2 n7 n1
R R3 n7 n5
```
3. PREDICTION: S11_max improves from -4.9 dB to about -12 dB (+7 dB). NF falls by about 0.3 dB because a noiseless real match replaces the lossy one. S21 rises by about 3 dB from the input Q gain. Ls degeneration also raises wideband mu by about 0.1-0.2.

==== ANSWER t2-nb090-noise-0143 ====
1. DIAGNOSIS
The binding constraint is NF: 2.54 dB against 2.29 dB. Stability is marginal (mu about 1.01) and everything else is pinned. The input is a series L1 into the purely capacitive inverter gate, which has no noiseless real input resistance. Most of the real part needed for S11 of about -8 dB has to come from lossy elements at the high-Q gate node: the bias-feed resistors R2 (NMOS gate) and R5 (PMOS gate, coupled via C1) and the gate resistance. The resonant input network multiplies their thermal noise by its Q. The same high-Q, lightly damped input together with the inductive output tank is why mu sits right at 1. With no inductive degeneration, the optimizer cannot obtain a 50-ohm real part from gm, so NF is held about 0.25 dB above the gate.

2. EDIT: inductive source degeneration on the NMOS. Ls goes from the NM1 source to VSS (a DC short, so the bias is unchanged). Re{Zin} = gm_n*Ls/C_in then supplies a noiseless 50-ohm real part, so the bias resistors can be made large and the match no longer relies on lossy resistance. Ls also gives series feedback that raises input-port stability margin.
```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n2 n1 ns VSS
L Ls ns VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```
3. PREDICTION: NF improves from 2.54 dB to about 2.15-2.25 dB (-0.3 to -0.4 dB). S11 is maintained at about -9 dB. S21 falls by about 0.3 dB at fixed sizing, which the optimizer recovers through the gate-L Q. mu rises to about 1.05.

C C1 VIN1 n1
R R1 n1 n2

NMOS NM2 n2 VDD nc VSS
L L1 VDD n3
R R2 n3 n2

==== ANSWER t2-nb090-noise-0129 ====

L Ls ns VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
