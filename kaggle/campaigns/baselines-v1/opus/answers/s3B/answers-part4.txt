==== ANSWER t2-wb1020-gain-0027 ====
1. DIAGNOSIS
The binding metric is mu_min_wide = 0.880, with in-band mu 1.09. The current-reuse inverter is a single undamped gain node:
- The gate is driven through the series inductor L1, an inductive source termination.
- The output n2 sees only ro_n||ro_p and the L2-C2 branch, which is inductive above its series resonance (s22_max -4.7 dB).
Through Cgd_n + Cgd_p (s12 -24.7 dB), these terminations form a tuned-gate/tuned-drain negative-resistance mechanism out of band. With s21, NF, s11 and Idd all pinned at their gates, the sizer has no damping knob.

2. EDIT: add resistive shunt feedback R6 from the output n2 to the NMOS gate n1, and self-bias NM1 through it.
- This removes the NMOS mirror reference R1/NM3/R2 and returns its current to the core.
- It gives broadband resistive coupling and loss between the ports, so the negative conductance disappears and |s22| drops.
- L1 keeps the in-band match.
```netlist
* lna-a2-current-reuse edit: resistive shunt feedback R6 (out->NMOS gate), NM1 self-biased via R6
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n2 n1 VSS VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R6 n2 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```
3. PREDICTION
- Binding metric: mu_min_wide improves from 0.880 to ~1.15-1.3 (about +0.3).
- s22_max: improves by ~4 dB.
- s21: changes by roughly -0.5 to +0.5 dB.
- NF: rises ~+0.1 dB.

==== ANSWER t2-nb090-noise-0286 ====
1. DIAGNOSIS
The binding s11_max_db (-3.68 dB vs -7.85 dB) is a missing input-match structure. NM1's gate is driven straight through C1, with only the bias resistor R2 in shunt. Zin is roughly R2 || 1/(jwCgs): reactive at 900 MHz, with no noiseless 50-ohm real part and nothing to resonate Cgs.
Terminating with R2 would wreck NF, which is at its gate (1.500 vs 1.5001 dB). So |Gamma| stays near 0.65.
The large gain miss (13.77 vs >=19.44 dB) comes from the same mismatch: reflected power, and no series-resonant voltage gain at the gate. Stability is fine in band (mu 2.32).

2. EDIT: an inductively degenerated stage-1 input.
- Series gate inductor L4 resonates Cgs.
- Source inductor L5 gives a noiseless Re{Zin} = wT*Ls = 50 ohm.
- Interstage L2 is removed to respect the 4-inductor screen. C2 couples directly to NM2, and L1 tunes the interstage node.
```netlist
* lna-a4-twostage edit: inductively degenerated stage-1 input (Lg=L4, Ls=L5), C-coupled interstage
C C1 VIN1 n0
L L4 n0 n1
NMOS NM1 n2 n1 n8 VSS
L L5 n8 VSS
L L1 VDD n2
C C2 n2 n5
NMOS NM2 n6 n5 VSS VSS
L L3 VDD n6
C C3 n6 VOUT1
R R1 VDD n7
NMOS NM3 n7 n7 VSS VSS
R R2 n7 n1
R R3 n7 n5
```
3. PREDICTION
- Binding metric: s11_max_db improves from -3.68 dB to about -12 dB (~8 dB better), clearing the gate.
- s21: rises ~+3 to +5 dB.
- NF: moves by roughly +/-0.2 dB.
- mu: stays >1.

==== ANSWER t2-wb1020-gain-0088 ====
1. DIAGNOSIS
The binding metric is mu_min_wide (0.01-50 GHz) = 0.716, with in-band mu 1.15. NM1 is a single common-source device whose Cgd couples the gate to a shunt-peaked drain (R2+L1) that is inductive at multi-GHz. The Miller term through Cgd then has a negative real part at both ports.
The R1 feedback gives a strong reverse path (s12 -19.5 dB), so mu falls below 1 out of band. To keep in-band stability the sizer had to give up gain: s21 is 9.26 vs >=11.64 dB, at the Idd cap.

2. EDIT: cascode NM2 (gate at VDD) between NM1's drain and the output/peaking node, with R1 still from the output to NM1's gate.
- The cascode isolates Cgd1 from the inductive load, which removes the negative conductance.
- It also raises the output resistance, so the loop gives more gain at the same match and Idd.
```netlist
* lna-a3-shunt-feedback edit: cascode NM2 (gate at VDD) inside the R1 feedback loop
C C1 VIN1 n1
R R1 n1 n2
NMOS NM1 n4 n1 VSS VSS
NMOS NM2 n2 VDD n4 VSS
L L1 VDD n3
R R2 n3 n2
C C2 n2 VOUT1
```
3. PREDICTION
- Binding metric: mu_min_wide improves from 0.72 to ~1.05-1.15 (about +0.35-0.4).
- s21: rises ~+1.5 to +2 dB.
- NF: rises by at most 0.2 dB.
