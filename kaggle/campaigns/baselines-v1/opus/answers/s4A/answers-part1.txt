==== ANSWER t2-nb090-noise-0013 ====
1. DIAGNOSIS
The binding constraint is broadband stability (mu_min over 0.01-50 GHz = 0.916), while every in-band metric (NF, S21, Idd) has been pushed to its limit and in-band mu is only 1.03. The current-reuse stage is a single transconductor with no cascode. NM1 and PM1 share the high-impedance output node n2. PM1's gate is AC-tied to the input through C1, so the Cgd of both devices feeds n2 back to the input. Isolation is poor (S12 ~ -25 dB, k_f0 = 1.07).

The drain load is L2, shunted to AC ground by C2. Below the tank resonance this load is inductive. Cgd Miller feedback into an inductive load puts a negative real part on the gate. The gate already sits behind a high-Q series inductor (L1) and has no noiseless real input resistance: there is no degeneration, and the only resistance is the bias feeds R2/R5. So off-resonance nothing damps that negative conductance, and mu falls below 1.

The sizer cannot fix this with sizing. Any gm/gain that would buy NF and S21 also deepens the Miller feedback, which is why NF, S21 and mu all sit at zero margin together.

2. EDIT: cascode NM1 (cascode gate tied to VDD) to break the inductive-load -> gate Cgd path, and add a source-degeneration inductor L3 on NM1. L3 supplies a noiseless real input resistance (gm*Ls/Cgs) in place of the Miller-derived one (inductively-degenerated cascode current-reuse stage, 3 inductors total).
```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n7 n1 n8 VSS
L L3 n8 VSS
NMOS NM4 n2 VDD n7 VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R1 VDD n5

R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```
