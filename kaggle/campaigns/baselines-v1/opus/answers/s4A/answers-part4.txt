==== ANSWER t2-wb1020-gain-0183 ====
1. DIAGNOSIS
The binding constraint is broadband stability (mu_min over 0.01-50 GHz = 0.71; in-band mu = 1.13), with S21 2.4 dB short (9.64 against 12.04 dB). The shunt-peaked load (L1 in series with R2) turns the drain impedance inductive above R2/L1. Through Cgd and the feedback resistor R1, that inductive load shows up as negative conductance at the input and output out of band, so mu drops to 0.71.

Gain is capped at about 1 - gm*Z0 by a single NMOS at the 9.3 mA cap. NF has 2.2 dB of slack.

2. EDIT: replace the L1+R2 load with a PMOS driven by the same input gate, making a resistive-feedback CMOS inverter LNA (current reuse). This edit:
- removes the inductor, so the network is RC-only and stable;
- gives gm_n + gm_p at the same current, for about +60-80% gm and higher S21;
- keeps R1 setting the broadband 50-ohm match and the self-bias.
```netlist
C C1 VIN1 n1
R R1 n1 n2
NMOS NM1 n2 n1 VSS VSS
PMOS PM1 n2 n1 VDD VDD
C C2 n2 VOUT1
```
3. PREDICTION: mu_min_wide (binding) improves from 0.71 to ~1.2+ (+0.5). S21 rises by ~2.5-3 dB to ~12-12.5 dB, and NF_max stays ~1.5-1.8 dB.

==== ANSWER t2-nb090-noise-0350 ====
1. DIAGNOSIS
The binding constraint is input match (S11 = -2.3 dB against -7.85 dB), with S21 8 dB short (15.0 against 22.8 dB). The input is C1 straight onto the gate of NM1 with only the bias feed R2 in shunt. The port therefore sees C1 in series with Cgs, nearly lossless, with no 50-ohm real part.

A small R2 would supply resistance but add input thermal noise, and NF is pinned at its limit (1.148 against 1.146). The mismatch loss (~4 dB) is most of the gain shortfall. Stage 2 (series gate L2 plus the L1 tank, drain tank L3, Cgd) is a tuned-gate/tuned-drain loop that sets mu over 0.01-50 GHz to 0.83.

2. EDIT: build an inductively-degenerated cascode input stage.
- Add a series gate inductor Lg and a source inductor Ls, giving a noiseless resonant real input of gm*Ls/Cgs = 50 ohm.
- Remove the interstage L2 to stay at 4 inductors and break stage 2's tuned gate.
- Cascode both stages, with their cascode gates tied to VDD.
```netlist
C C1 VIN1 n0
L Lg n0 n1
NMOS NM1 n8 n1 n3 VSS
L Ls n3 VSS
NMOS NM4 n2 VDD n8 VSS
L L1 VDD n2
C C2 n2 n5
NMOS NM2 n9 n5 VSS VSS
NMOS NM5 n6 VDD n9 VSS
L L3 VDD n6
C C3 n6 VOUT1
R R1 VDD n7
NMOS NM3 n7 n7 VSS VSS
R R2 n7 n1
R R3 n7 n5
```
3. PREDICTION: s11_max_db (binding) improves from -2.3 dB to ~-11 dB (about 9 dB better). S21 rises by ~7 dB to ~22 dB, NF stays ~1.1-1.2 dB, and mu_min_wide rises above 1.

==== ANSWER t2-nb090-noise-0307 ====
1. DIAGNOSIS
The binding constraint is input match (S11 = -4.9 dB against -7.85 dB). Stage 1 has no matching network: C1 feeds the gate of NM1 directly, shunted only by the bias feed R2. The input impedance is C1 in series with Cgs, almost purely reactive. The only resistive lever, R2, injects noise at the input, and NF is at its limit (2.017 against 2.018).

In addition, stage 2's series gate inductor L2 plus the L1 tank, together with the L3 drain tank and Cgd, form a tuned-gate/tuned-drain loop, giving mu over 0.01-50 GHz of 0.77 even though in-band mu is 2.4.

2. EDIT: make stage 1 an inductively-degenerated cascode.
- Add Lg in series with the gate and Ls at the NM1 source, for a noiseless resonant 50-ohm real part, gm*Ls/Cgs.
- Delete the interstage L2 (keeping the 4-inductor budget and removing stage 2's tuned gate).
- Cascode both stages, with their cascode gates tied to VDD.
```netlist
C C1 VIN1 n0
L Lg n0 n1
NMOS NM1 n8 n1 n3 VSS
L Ls n3 VSS
NMOS NM4 n2 VDD n8 VSS
L L1 VDD n2
C C2 n2 n5
NMOS NM2 n9 n5 VSS VSS
NMOS NM5 n6 VDD n9 VSS
L L3 VDD n6
C C3 n6 VOUT1
R R1 VDD n7
NMOS NM3 n7 n7 VSS VSS
R R2 n7 n1
R R3 n7 n5
```
3. PREDICTION: s11_max_db (binding) improves from -4.9 dB to ~-12 dB (about 7 dB better). S21 rises by ~4-6 dB, NF stays ~1.8-2.0 dB, and mu_min_wide rises above 1.

==== ANSWER t2-wb1020-gain-0089 ====
1. DIAGNOSIS
The binding constraint is broadband stability (mu_min over 0.01-50 GHz = 0.95; in-band mu = 1.08; S12 = -26 dB). In the un-cascoded current-reuse stage, output n2 feeds back to the input through the Cgd of NM1 and PM1 (PM1's gate is AC-coupled to the input by C1).

Below its resonance the L2 tank (AC-grounded by C2) is inductive, where Miller feedback gives the gate a negative conductance. The input (series L1 into Cgs) has no degeneration resistance to damp it, so mu falls below 1 out of band. NF_max, S21 and Idd are all at zero margin, so the sizer cannot give up gain for stability.

2. EDIT: cascode NM1 (cascode gate to VDD) to break the load -> gate feedback, and add a source-degeneration inductor L3 on NM1 for a noiseless real input resistance (inductively-degenerated cascode current-reuse stage).
```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n7 n1 n8 VSS
L L3 n8 VSS
NMOS NM4 n2 VDD n7 VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```
3. PREDICTION: mu_min_wide (binding) improves from 0.95 to ~1.15 (+0.2). S12 improves by ~10 dB, and S21 gains ~1-2 dB.

==== ANSWER t2-nb090-noise-0143 ====
1. DIAGNOSIS
The binding constraint is noise figure (2.54 dB against 2.29 dB), with in-band mu (1.011), k (1.02), S11, S21 and Idd all at zero margin. In the un-cascoded current-reuse stage, n2 feeds back to the input through the Cgd of NM1 and PM1 (PM1's gate is AC-coupled by C1), so S12 = -25 dB. With the inductive L2 load, any increase in gm or gate-voltage gain, which is what would lower NF, pushes k and mu below 1. The sizer is therefore stability-limited, not noise-limited.

The input also has no noiseless real part: there is no degeneration. The 50-ohm match leans on Miller feedback and the bias feeds R2/R5. The resistors add thermal noise at the gate, and the noise optimum cannot coincide with the power match.

2. EDIT: build an inductively-degenerated cascode current-reuse stage.
- Add a source inductor L3 on NM1, giving a noiseless real input resistance (gm*Ls/Cgs), so R2/R5 can go large and the noise and power matches align.
- Add an NMOS cascode NM4 (gate to VDD), which removes the Miller path from the inductive load and so lifts the mu = 1 ceiling on gm and gain.
```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n7 n1 n8 VSS
L L3 n8 VSS
NMOS NM4 n2 VDD n7 VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```
3. PREDICTION: nf_db (binding) improves by ~0.3-0.35 dB, from 2.54 to ~2.2 dB. In-band mu rises to ~1.3 and S12 improves by ~10 dB, while S11 and S21 hold.
