==== ANSWER t2-nb090-noise-0387 ====
1. DIAGNOSIS
The binding constraint is s11_max_db (-5.0 dB achieved against a -7.85 dB gate). The input of stage 1 is just DC-block C1 straight onto the gate of NM1, so at 900 MHz Zin is basically Cgs1 in parallel with the bias feed resistor R2. The input network has no device that makes a noiseless 50-ohm real part and nothing that resonates out Cgs. The optimizer can get a partial match only by trading R2 (which adds noise and is already at the NF edge) against Cgs, and that tops out near -5 dB. Gain (13.95 dB) and Idd are also at their edges because the input mismatch wastes available gain.

2. EDIT: inductively degenerated input on stage 1, plus a cascode on stage 1
- Add a series gate inductor (L4) and a source-degeneration inductor (L5) on NM1. The real part is gm*Ls/Cgs = wT*Ls, which gives a noiseless 50-ohm input. Lg+Ls resonate Cgs at f0.
- The interstage series L2 is removed so the circuit stays within the 4-inductor screen. C2 now couples straight to the NM2 gate, and L1 resonates the NM2 gate capacitance.
- A cascode NM4 (gate to VDD) is added on stage 1. It recovers the gain lost from L2 and improves isolation, so the input match does not depend on the load.
```netlist
C C1 VIN1 n0
L L4 n0 n1
NMOS NM1 n8 n1 n9 VSS
L L5 n9 VSS
NMOS NM4 n2 VDD n8 VSS
L L1 VDD n2
C C2 n2 n5
NMOS NM2 n6 n5 VSS VSS
L L3 VDD n6
C C3 n6 VOUT1
R R1 VDD n7
NMOS NM3 n7 n7 VSS VSS
R R2 n7 n1
R R3 n7 n5
```
3. PREDICTION
s11_max_db should improve by about 7 dB, from -5.0 to about -12 dB, and pass. The Q-boost of the input network should also raise s21 by about 2-3 dB. NF should stay at about 2 dB.

==== ANSWER t2-wb1020-gain-0088 ====
1. DIAGNOSIS
The binding constraint is the wideband stability factor mu_min_wide (0.72 over 0.01-50 GHz). s21 also falls short (9.3 vs 11.6 dB).
- The single shunt-feedback CS has a large direct reverse path. S12 is only about -19.5 dB, through the feedback resistor R1 in parallel with Cgd of NM1. The shunt-peaking inductor makes the drain impedance rise and turn reactive above the band.
- Out of band, |S11| and |S22| approach 1 (reactive terminations: DC blocks, Cgs, L1), so the residual S12*S21 product drives mu below 1.
- Gain is capped because the output resistance is ro(NM1) in parallel with R2/L1 in parallel with R1 into a 50-ohm load, at the fixed current budget.

2. EDIT: cascode the shunt-feedback CS
Add NM2 (gate to VDD) between NM1 and the shunt-peaked load. The feedback R1 is taken from the cascode drain (the output) back to the gate, so self-bias is kept.
- The cascode removes the Cgd Miller/reverse path from the output, so S12 drops by about 10+ dB.
- It also raises the output resistance, so gm*Rload and s21 go up.
```netlist
C C1 VIN1 n1
R R1 n1 n2
NMOS NM1 n4 n1 VSS VSS
NMOS NM2 n2 VDD n4 VSS
L L1 VDD n3
R R2 n3 n2
C C2 n2 VOUT1
```
3. PREDICTION
mu_min_wide should rise from 0.72 to about 1.05-1.15 (+0.35) and pass. s21 should improve by about 2-3 dB, to about 11.5-12 dB.

==== ANSWER t2-wb1020-gain-0159 ====
