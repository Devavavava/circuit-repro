==== ANSWER t2-wb1020-gain-0045 ====
1. DIAGNOSIS
The binding constraint is mu_min_wide (0.974, just below 1).
- The current-reuse inverter puts the Cgd of NM1 and PM1 in parallel between the output n2 and the AC-tied gates, giving a sizeable reverse path (S12 about -25.9 dB).
- The output is poorly loaded (s22_max about -3 dB, so the output port is close to reflective), and the input is a series-L1/Cgs reactive network.
- Away from the band, both ports become nearly lossless while S12*S21 stays finite, so mu dips below 1.

2. EDIT: NMOS cascode in the current-reuse stack
Add NM2 (gate to VDD) between n2 and the NM1 drain. This removes the NMOS Cgd from the output-to-input feedback path, so S12 drops by about 6-10 dB. With S12*S21 smaller, mu approaches 1/|S22| at least. It also adds output resistance and therefore gain margin.
```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n7 n1 VSS VSS
NMOS NM2 n2 VDD n7 VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```
3. PREDICTION
mu_min_wide should improve by about 0.1-0.15, from 0.97 to about 1.08-1.12, and pass. s21 should improve by about 1 dB.

==== ANSWER t2-nb090-noise-0375 ====
1. DIAGNOSIS
The binding constraint is s11_max_db (-2.4 dB against a -7.84 dB gate). s21 is also 2.75 dB short.
- The NM1 gate is fed directly through C1, so at 900 MHz Zin is a high-Q capacitive Cgs1 in parallel with bias R2. There is no noiseless real part and no inductor to resonate out Cgs.
- NF is pinned at 1.24 dB, so R2 cannot be lowered to make a resistive input. The input is almost totally reflective, and the mismatch costs several dB of S21.

2. EDIT: inductively degenerated input (series Lg + source Ls) on NM1, plus a cascode on stage 1
- L4 and L5 give Re{Zin} = wT*Ls = 50 ohm and resonate Cgs1 at 900 MHz. This is a noiseless real match, and the input network Q adds voltage gain.
- L2 is removed to stay within 4 inductors. C2 couples directly and L1 tunes the stage-1 drain plus the NM2 gate.
- Cascode NM4 raises the stage-1 gain and isolation.
```netlist
C C1 VIN1 n0
L L4 n0 n1
NMOS NM1 n8 n1 n9 VSS
L L5 n9 VSS
NMOS NM4 n2 VDD n8 VSS
L L1 VDD n2
C C2 n2 n5
NMOS NM2 n6 n5 VSS VSS
L L3 VDD n6
C C3 n6 VOUT1
R R1 VDD n7
NMOS NM3 n7 n7 VSS VSS
R R2 n7 n1
R R3 n7 n5
```
3. PREDICTION
s11_max_db should improve by about 8-9 dB, from -2.4 to about -11 dB. s21 should rise by about 3-4 dB, to about 18 dB. NF should stay at about 1.2 dB.

==== ANSWER t2-wb1020-gain-0205 ====
1. DIAGNOSIS
The binding constraint is mu_min_wide (0.73).
- The single-transistor shunt-feedback CS has a strong reverse path: S12 is about -18 dB through R1 plus Cgd of NM1, which sits directly between the output and the input.
- The shunt-peaking inductor L1 raises the drain impedance and adds phase above the band. Out of band, the terminations become reactive (DC blocks, Cgs, drain capacitance), so |S11| and |S22| approach 1 while S12*S21 remains, and mu falls well below 1.
- Gain is also exactly at its floor, because the single-stage gm*Rload at 9 mA is limited by ro in 45 nm.

2. EDIT: cascode the shunt-feedback amplifier
Add NM2 (gate to VDD) on top of NM1. Feedback R1 is taken from the cascode drain (the output) to the gate, so self-bias is kept. This removes the Cgd/Miller reverse path, leaving only the intentional R1 path, and lifts the output resistance (more gain for the same current).
```netlist
C C1 VIN1 n1
R R1 n1 n2
NMOS NM1 n4 n1 VSS VSS
NMOS NM2 n2 VDD n4 VSS
L L1 VDD n3
R R2 n3 n2
C C2 n2 VOUT1
```
3. PREDICTION
mu_min_wide should improve by about 0.3, from 0.73 to about 1.0-1.1. s21 should improve by about 2 dB.

==== ANSWER v2b-wb0824-gain-188 ====
1. DIAGNOSIS
The binding constraint is nf_max_db (2.50 against a 2.04 dB gate over 0.8-2.4 GHz).
- The current-reuse inverter has no noiseless way to make a real input resistance. Apart from gate resistance, the only real part at the gate comes from the bias feed resistors R2 (NMOS gate) and R5 (PMOS gate through C1). Matching s11 to about -9 dB therefore means terminating the input in physical resistors, whose thermal noise adds directly. A shunt-resistor match sets an NF floor close to 3 dB at the band edges.
- The series L1 + Cgs resonance also only matches near the center, so at 0.8 and 2.4 GHz the match and the noise both degrade.

2. EDIT: resistive shunt feedback (resistive-feedback inverter LNA)
Add Rf from the output n2 back to the NMOS gate n1, through a DC-block cap so the published bias is kept. The gates are AC-tied by C1, so this is feedback around the whole inverter.
- The input resistance becomes about Rf/(1 + gm_total*Rout). This is a broadband real part produced by feedback, not by a grounded resistor, so its noise is divided by the loop gain.
- R2 and R5 can be made large, which removes their noise.
- The feedback also flattens the match over the 3:1 band and damps the output, which helps mu_wide (0.90).
```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n2 n1 VSS VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R6 n2 n8
C C5 n8 n1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```
3. PREDICTION
nf_max_db should improve by about 0.5-0.7 dB, from 2.50 to about 1.85-2.0 dB. s11_max should improve by about 1-2 dB, and mu_min_wide should rise to about 1.0 or above.

==== ANSWER t2-wb1020-gain-0046 ====
1. DIAGNOSIS
The binding constraint is mu_min_wide (0.885). In-band mu_min (0.888, k about 0.29) fails as well.
- The output is almost totally reflective (s22 is about -0.24 dB, s22_max about -0.04 dB). The shared drain n2 has a very high, almost lossless impedance: the inverter output resistance ro_n || ro_p in parallel with the L2-C2 tank, with no resistive loading.
- With |S22| close to 1, the numerator terms of mu collapse, and any S12*S21 (Cgd of both devices) makes the stage potentially unstable in band and beyond.
- The source-side mu (mu_src_min about 0.03) shows the problem is the output port.

2. EDIT: resistive shunt feedback around the inverter
Add Rf (with a DC-block cap) from the output n2 back to the gate n1. Shunt-shunt feedback lowers the output impedance to about (Rf + Rs_eff)/(1 + gm*Rs_eff), which gives a resistive output match. It damps the output tank Q and sets a well-defined broadband input real part. Together these make both ports lossy, so |S11| and |S22| stay well below 1 and mu rises above 1. The DC block keeps the published bias networks in control of the gate DC.
```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n2 n1 VSS VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R6 n2 n8
C C5 n8 n1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```
3. PREDICTION
mu_min_wide should rise by about 0.25, from 0.885 to about 1.1-1.2, and in-band mu_min should go above 1. s22_max should improve by about 6-8 dB, to about -7 dB. s21 should drop by about 0.5 dB at most, which the optimizer can recover with current headroom.
