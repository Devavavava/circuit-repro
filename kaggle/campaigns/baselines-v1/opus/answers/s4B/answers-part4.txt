==== ANSWER t2-nb090-noise-0291 ====
1. DIAGNOSIS
The binding constraint is s11_max_db (-3.6 dB against a -7.9 dB gate). s21 is also 4.6 dB short.
- Stage 1 receives the input through C1 directly on the NM1 gate, so Zin at 900 MHz is a high-Q capacitive Cgs1 in parallel with bias R2.
- No element synthesizes a noiseless 50-ohm real part, and nothing resonates Cgs. Because NF is held at 1.48 dB, the sizer cannot use a small R2 to make a real part, so the input stays badly mismatched. That mismatch, plus the missing input-network voltage gain, also explains the S21 shortfall.

2. EDIT: inductive source degeneration plus a series gate inductor on NM1, and a cascode on stage 1
- L4 (Lg) and L5 (Ls) set Re{Zin} = wT*Ls = 50 ohm and resonate Cgs1 at f0. This is a noiseless match whose input Q also gives voltage gain.
- L2 is dropped to stay within the 4-inductor screen. C2 couples directly and L1 tunes the stage-1 drain plus the NM2 gate.
- Cascode NM4 raises stage-1 gain and isolation.
```netlist
C C1 VIN1 n0
L L4 n0 n1
NMOS NM1 n8 n1 n9 VSS
L L5 n9 VSS
NMOS NM4 n2 VDD n8 VSS
L L1 VDD n2
C C2 n2 n5
NMOS NM2 n6 n5 VSS VSS
L L3 VDD n6
C C3 n6 VOUT1
R R1 VDD n7
NMOS NM3 n7 n7 VSS VSS
R R2 n7 n1
R R3 n7 n5
```
3. PREDICTION
s11_max_db should improve by about 7-8 dB, from -3.6 to about -11 dB. s21 should rise by about 4-5 dB, to about 18.5 dB. NF should stay at about 1.4 dB.

==== ANSWER t2-wb1020-gain-0107 ====
1. DIAGNOSIS
The binding constraint is mu_min_wide (0.71). s21 is also 1.5 dB short.
- In the shunt-feedback CS, the output connects back to the input through R1 in parallel with Cgd(NM1), so S12 is about -19.4 dB.
- The shunt-peaking L1 produces a rising, phase-shifted drain impedance above the band. Out of band, the terminations go reactive (C1/C2 DC blocks, Cgs, drain capacitance), so |S11| and |S22| approach 1 while S12*S21 remains, giving mu well under 1.
- At 7.3 mA a single 45 nm device with low ro limits gm*Rout, and with it the gain.

2. EDIT: cascode the shunt-feedback CS
Add NM2 (gate to VDD) stacked on NM1, with feedback R1 from the cascode drain (the output) to the gate, so self-bias is kept. This removes the Cgd/Miller reverse path and boosts the output resistance, which recovers gain.
```netlist
C C1 VIN1 n1
R R1 n1 n2
NMOS NM1 n4 n1 VSS VSS
NMOS NM2 n2 VDD n4 VSS
L L1 VDD n3
R R2 n3 n2
C C2 n2 VOUT1
```
3. PREDICTION
mu_min_wide should improve by about 0.3-0.35, from 0.71 to about 1.0-1.05. s21 should improve by about 2 dB, to about 11 dB.

==== ANSWER t2-nb090-noise-0068 ====
1. DIAGNOSIS
The binding constraint is mu_min_wide (0.874). In-band mu (1.009, k about 1.03) is also marginal, and s21 is 0.6 dB short.
- The current-reuse inverter couples the shared drain n2 back to the AC-tied NMOS/PMOS gates through both Cgd's (S12 about -25.9 dB, large for a 14.5 dB-gain stage).
- The output is poorly loaded (s22 about -4.2 dB), and the input is a series L1 into the gate-capacitance resonance. In band, and even more out of band, both ports are close to lossless, so the S12*S21 loop puts mu below 1.
- The low ro_n || ro_p output resistance in 45 nm also caps the gain at 6 mA.

2. EDIT: NMOS cascode in the current-reuse stack
Add NM2 (gate to VDD) between n2 and the NM1 drain. This shields the NMOS Cgd from the output, so S12 falls by about 6-10 dB. It also raises the output resistance, so gain increases at the same 6 mA.
```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n7 n1 VSS VSS
NMOS NM2 n2 VDD n7 VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```
3. PREDICTION
mu_min_wide should improve by about 0.2, from 0.87 to about 1.05-1.1. In-band mu should rise to about 1.3. s21 should improve by about 1 dB, to about 15.5 dB.

==== ANSWER t2-wb1020-gain-0142 ====
1. DIAGNOSIS
The binding constraint is mu_min_wide (0.895). In-band mu (1.00002) and k_min (1.00005) are exactly at the edge, which shows the sizer was stability-limited. s21 is also 0.2 dB short.
- The current-reuse inverter's combined Cgd (NMOS plus PMOS) from n2 to the AC-tied gates gives S12 of about -25.2 dB.
- The output is poorly loaded (s22_max about -3.2 dB), and the input is a reactive series-L1 network. With both ports near-lossless out of band, S12*S21 forces mu below 1. Inside the band, the sizer had to give up gain to keep mu at 1.

2. EDIT: NMOS cascode in the current-reuse stack
Add NM2 (gate to VDD) between n2 and the NM1 drain. This cuts the NMOS Cgd reverse path, which lowers S12 and frees the stability constraint, and raises the output resistance (more gain at the same current).
```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n7 n1 VSS VSS
NMOS NM2 n2 VDD n7 VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```
3. PREDICTION
mu_min_wide should improve by about 0.15-0.2, from 0.89 to about 1.05-1.1. In-band mu_min should rise to about 1.2. s21 should improve by about 1 dB, to about 14.4 dB.
