1. DIAGNOSIS
The binding failure is NF (2.54 vs 2.29 dB). NM1's source is grounded directly, so the input has no noiseless real part. The 50-ohm match is made as an L-match: series L1 resonating Cgs, with the real part supplied by the gate bias-feed resistor R2 (to the low-impedance mirror node). R2's thermal noise lands directly on the gate, and the device can't be placed at its optimum noise source impedance. That is a resistive-termination noise penalty. s11, s21, Idd and mu are all pinned at their gates, so the sizer has no freedom left to trade for NF.

2. EDIT: add an inductive source-degeneration inductor (L3) from NM1's source to ground. It creates a noiseless input real part wT*Ls, so the 50-ohm match no longer has to come from R2 (which the sizer can make large, as a pure bias feed). The input then approaches simultaneous noise and power match. The series feedback also helps the marginal stability.
```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n2 n1 n7 VSS
L L3 n7 VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```
3. PREDICTION: nf_db improves from 2.54 dB to about 2.0 dB (about 0.5 dB better; it passes 2.29 dB). s11 stays at -8 dB or better (match from wT*Ls). s21 is about 0.5 dB lower from degeneration, which the sizer compensates through the higher input-resonance Q. mu_min rises a little above 1.01.
