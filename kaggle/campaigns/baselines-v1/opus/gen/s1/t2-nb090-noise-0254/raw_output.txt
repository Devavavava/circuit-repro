1. DIAGNOSIS
The binding failure is the input match (s11 = -3.0 dB). C1 connects straight to NM1's gate, so the input impedance is Cgs in parallel with a large bias resistor R2: almost purely capacitive at 900 MHz, with no real part near 50 ohm and |Gamma| close to 1. The NF budget (1.35 dB) forbids using a small R2 as the termination, so the sizer can't fix the match with the parts it has. The same mismatch, and the lack of input-resonance gate gain, keeps s21 at 14.6 vs 20.1 dB.

2. EDIT: make stage 1 an inductively degenerated CS: a series gate inductor (L4) after the DC block and a source inductor (L5) from NM1's source to ground. This gives a noiseless Re(Zin) = wT*Ls and resonant cancellation of Cgs. To respect the 4-inductor limit, the interstage series L2 is removed, and C2 couples stage 1 directly to NM2's gate, with L1 now resonating the stage-1 drain plus Cgs2. The mirror bias is unchanged.
```netlist
C C1 VIN1 n0
L L4 n0 n1
NMOS NM1 n2 n1 n8 VSS
L L5 n8 VSS
L L1 VDD n2
C C2 n2 n5
NMOS NM2 n6 n5 VSS VSS
L L3 VDD n6
C C3 n6 VOUT1
R R1 VDD n7
NMOS NM3 n7 n7 VSS VSS
R R2 n7 n1
R R3 n7 n5
```
3. PREDICTION: s11_max_db improves from -3.0 dB to about -11 dB (about 8 dB better; it passes). Side effects: s21 gains about 5 dB from the recovered mismatch loss plus the gate Q boost, NF stays about 1.3 dB, and mu_wide improves (no series L2/Cgs2 resonance, and Ls adds a positive input real part).
