1. DIAGNOSIS
The binding failure is the input match (s11 = -3.9 dB). The input is a DC-block cap straight into NM1's gate, so Zin is Cgs in parallel with the large bias-feed R2: strongly capacitive at 900 MHz, with no real part near 50 ohm. Nothing synthesizes a resistive input, and a small R2 would break the 1.72 dB NF. Gain (12.1 dB) is only barely met, and only by burning the whole current.

2. EDIT: add a classic inductively degenerated input: series gate inductor L4 (after C1) plus source inductor L5 (NM1 source to ground). Re(Zin) = wT*Ls is set to about 50 ohm with no noise, and Lg + Ls tune out Cgs at 900 MHz. The interstage series L2 is dropped to stay within the 4-inductor limit; C2 feeds NM2's gate directly and L1 resonates the stage-1 drain plus Cgs2. The bias is unchanged.
```netlist
C C1 VIN1 n0
L L4 n0 n1
NMOS NM1 n2 n1 n8 VSS
L L5 n8 VSS
L L1 VDD n2
C C2 n2 n5
NMOS NM2 n6 n5 VSS VSS
L L3 VDD n6
C C3 n6 VOUT1
R R1 VDD n7
NMOS NM3 n7 n7 VSS VSS
R R2 n7 n1
R R3 n7 n5
```
3. PREDICTION: s11_max_db improves from -3.9 dB to about -12 dB (about 8 dB better; it passes -7.86). Side effects: s21 rises by about 3-5 dB, which gives the sizer room to cut current for NF and Idd margin. NF stays about 1.6 dB, and mu_wide improves (the interstage series resonance is removed).
