1. DIAGNOSIS
The binding failure is the input match (s11 = -3.0 dB). The input is a DC-block cap straight into NM1's gate, so Zin is Cgs in parallel with a large bias resistor R2. That is almost purely reactive at 900 MHz, with no real part near 50 ohm and |Gamma| close to 1. A small R2 would provide a real part only at an unacceptable NF cost (the gate is 1.37 dB). The same mismatch, and the lack of input-resonance gate gain, keeps s21 at 14.0 vs 18.8 dB.

2. EDIT: use an inductively degenerated stage-1 input: series gate inductor L4 and source inductor L5 (NM1 source to ground). This gives a noiseless Re(Zin) = wT*Ls = 50 ohm and Lg + Ls resonance with Cgs. The interstage series L2 is removed to stay within 4 inductors; C2 feeds NM2's gate directly and L1 resonates the stage-1 drain plus Cgs2. The bias is unchanged.
```netlist
C C1 VIN1 n0
L L4 n0 n1
NMOS NM1 n2 n1 n8 VSS
L L5 n8 VSS
L L1 VDD n2
C C2 n2 n5
NMOS NM2 n6 n5 VSS VSS
L L3 VDD n6
C C3 n6 VOUT1
R R1 VDD n7
NMOS NM3 n7 n7 VSS VSS
R R2 n7 n1
R R3 n7 n5
```
3. PREDICTION: s11_max_db improves from -3.0 dB to about -11 dB (about 8 dB better; it passes -7.86). Side effects: s21 rises by about 4-6 dB (mismatch loss recovered, plus the gate Q boost), NF stays about 1.3 dB, and mu_wide improves (no series interstage resonance; Ls adds a positive input real part).
