1. DIAGNOSIS
The binding failure is the input match (s11 = -4.9 dB). The input DC block C1 feeds NM1's gate directly, so Zin at 900 MHz is Cgs in parallel with the large bias-feed R2: strongly capacitive, with no real part near 50 ohm. No element synthesizes a resistive input, and dropping R2 low enough to terminate the source would exceed the 2.02 dB NF limit. The mismatch also costs transducer gain, so s21, NF and Idd all sit at their gates.

2. EDIT: make stage 1 an inductively degenerated CS: a series gate inductor L4 after C1, plus a source inductor L5 from NM1's source to ground. This gives a noiseless Re(Zin) = wT*Ls (about 50 ohm), with Lg + Ls resonating Cgs at 900 MHz. To stay within the 4-inductor screen, the interstage series L2 is removed: C2 couples the L1-tuned stage-1 drain straight into NM2's gate, and L1 absorbs Cgs2. The mirror bias is unchanged.
```netlist
C C1 VIN1 n0
L L4 n0 n1
NMOS NM1 n2 n1 n8 VSS
L L5 n8 VSS
L L1 VDD n2
C C2 n2 n5
NMOS NM2 n6 n5 VSS VSS
L L3 VDD n6
C C3 n6 VOUT1
R R1 VDD n7
NMOS NM3 n7 n7 VSS VSS
R R2 n7 n1
R R3 n7 n5
```
3. PREDICTION: s11_max_db improves from -4.9 dB to about -12 dB (about 7 dB better; it passes -7.85). Side effects: s21 rises by about 3-5 dB, NF drops by about 0.2-0.4 dB, and mu_wide improves (no series L2/Cgs2 resonance; Ls adds a positive input real part).
