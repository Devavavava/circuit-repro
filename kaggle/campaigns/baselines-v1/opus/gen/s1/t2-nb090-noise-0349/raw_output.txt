1. DIAGNOSIS
The binding metric is s11_max_db at -2.8 dB. The input is just the DC block C1 to the NM1 gate, so the 900 MHz port sees Cgs in parallel with the R2 bias feed: strongly capacitive, essentially no 50-ohm real part, and nothing in the topology to transform it. The tight NF target (1.27 dB) pushed R2 high and NM1 large, which worsens the reactance. With no input series resonance, the gate voltage gets no Q multiplication, so S21 is also 4 dB short.

2. EDIT: inductively degenerate the first stage. Add a series gate inductor LG and a source-degeneration inductor LS on NM1, so that Re(Zin) = wT*LS = 50 ohm and Cgs resonates out at 900 MHz. This is a simultaneous noise and power match. The interstage series L2 is dropped, with C2 coupling straight to the NM2 gate, keeping 4 inductors (LG, LS, L1, L3).

```netlist
C C1 VIN1 n0
L LG n0 n1
NMOS NM1 n2 n1 n8 VSS
L LS n8 VSS
L L1 VDD n2
C C2 n2 n5
NMOS NM2 n6 n5 VSS VSS
L L3 VDD n6
C C3 n6 VOUT1
R R1 VDD n7
NMOS NM3 n7 n7 VSS VSS
R R2 n7 n1
R R3 n7 n5
```

3. PREDICTION: s11_max_db improves by about 8-10 dB, from -2.8 to about -11 to -13 dB. S21 improves by about 4 dB, to about 19 dB. NF stays at about 1.1-1.3 dB.
