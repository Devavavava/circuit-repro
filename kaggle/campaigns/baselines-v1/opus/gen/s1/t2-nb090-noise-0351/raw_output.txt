1. DIAGNOSIS
The binding metric is s11_max_db at -3.5 dB. Stage 1 is a bare CS gate behind the DC block C1, so at 900 MHz the input is Cgs in parallel with the R2 bias feed. That is nearly pure capacitance with no structural 50-ohm real part. NF is pinned at 1.43 dB and Idd at its cap, so the sizer cannot fix the match. With no gate series resonance, stage 1 gets no Q voltage gain, so S21 is also about 5 dB short.

2. EDIT: use the classic inductively degenerated CS input. Add a series gate inductor LG and a source inductor LS on NM1, giving Re(Zin) = wT*LS = 50 ohm and resonance with Cgs at 900 MHz, which also supplies gate-voltage gain. The interstage series L2 is removed, with C2 coupling directly to the NM2 gate and L1 as the tuned load, so the total stays at 4 inductors (LG, LS, L1, L3).

```netlist
C C1 VIN1 n0
L LG n0 n1
NMOS NM1 n2 n1 n8 VSS
L LS n8 VSS
L L1 VDD n2
C C2 n2 n5
NMOS NM2 n6 n5 VSS VSS
L L3 VDD n6
C C3 n6 VOUT1
R R1 VDD n7
NMOS NM3 n7 n7 VSS VSS
R R2 n7 n1
R R3 n7 n5
```

3. PREDICTION: s11_max_db improves by about 8-10 dB, from -3.5 to about -11 to -13 dB. S21 improves by about 4-5 dB, to about 18.5-19.5 dB. NF stays at about 1.3-1.45 dB.
