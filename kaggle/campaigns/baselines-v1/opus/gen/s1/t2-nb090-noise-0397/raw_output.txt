1. DIAGNOSIS
The binding failure is the input match (s11 = -2.7 dB). C1 connects straight to NM1's gate, so the input impedance is Cgs in parallel with a large bias resistor R2: almost purely reactive at 900 MHz, with |Gamma| close to 1 and no real part near 50 ohm. The tight NF limit (1.30 dB) forbids using a small R2 as the termination, so the sizer can't create a real part. The mismatch (about 3.5 dB of lost transducer gain), plus the lack of input-resonance gate gain, also holds s21 at 14.7 vs 16.5 dB.

2. EDIT: use an inductively degenerated stage-1 input: series gate inductor L4 after C1, and source inductor L5 from NM1's source to ground. This gives a noiseless Re(Zin) = wT*Ls = 50 ohm, with Lg + Ls tuning out Cgs at 900 MHz. The interstage series L2 is removed to respect the 4-inductor limit; C2 feeds NM2's gate directly and L1 resonates the stage-1 drain plus Cgs2. The mirror bias is unchanged.
```netlist
C C1 VIN1 n0
L L4 n0 n1
NMOS NM1 n2 n1 n8 VSS
L L5 n8 VSS
L L1 VDD n2
C C2 n2 n5
NMOS NM2 n6 n5 VSS VSS
L L3 VDD n6
C C3 n6 VOUT1
R R1 VDD n7
NMOS NM3 n7 n7 VSS VSS
R R2 n7 n1
R R3 n7 n5
```
3. PREDICTION: s11_max_db improves from -2.7 dB to about -11 dB (about 8 dB better; it passes -7.87). Side effects: s21 rises by about 4-6 dB (which clears 16.5 dB), NF stays about 1.2-1.3 dB, and mu_wide improves because the series L2/Cgs2 interstage resonance is gone.
