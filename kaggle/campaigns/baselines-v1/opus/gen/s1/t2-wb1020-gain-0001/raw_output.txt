1. DIAGNOSIS
The binding failure is wideband stability (mu over 0.01-50 GHz = 0.64), and s21 is slightly short (10.76 vs 11.11 dB). The shunt-peaked load (L1 in series with R2) turns inductive above the peaking zero. Fed back through Cgd and the feedback resistor R1, the input admittance jwCgd(1 + gm*jwL) gets a negative real part (-w^2*gm*L*Cgd) at multi-GHz frequencies, where the NMOS still has gain, so mu < 1. Gain is capped at the 9.8 mA cap: a single NMOS provides all the gm, and the DC-drop resistor R2 loads the output.

2. EDIT: replace the shunt-peaked NMOS CS with a self-biased CMOS inverter (NM1 + PM1) inside the same R1 shunt feedback (the inverter resistive-feedback broadband LNA). The current is reused (gm_n + gm_p), the PMOS is the active load, and there is no inductor, so the drain impedance stays RC. R1 sets Vg = Vd self-bias and the broadband real input match.
```netlist
C C1 VIN1 n1
R R1 n1 n2
NMOS NM1 n2 n1 VSS VSS
PMOS PM1 n2 n1 VDD VDD
C C2 n2 VOUT1
```
3. PREDICTION: mu_min_wide_0.01-50GHz improves from 0.64 to about 1.2 (about +0.55; it passes). Side effect: s21 rises by about 2-4 dB from the added PMOS gm, which clears 11.1 dB. Ripple stays below 0.5 dB and NF stays below about 2.5 dB.
