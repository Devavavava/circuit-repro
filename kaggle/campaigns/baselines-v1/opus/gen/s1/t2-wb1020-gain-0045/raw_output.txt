1. DIAGNOSIS
The worst failure is mu_min_wide at 0.974, a marginal out-of-band stability failure. S21 ripple (1.78 dB) and S21 (13.07 dB) are both at their limits, s22_max is -3.0 dB, and delta_max reaches 0.47. The high-gain current-reuse stage (9 mA, large gmn+gmp) drives a high-impedance shared drain with only the reactive L2-C2 trap. The input is the narrowband, high-Q series L1-Cgs resonance: s11 is -24.9 dB at f0 but only -7.9 dB at the band edges. Both ports are nearly lossless out of band and Cgd provides a reverse path, so mu dips just below 1 somewhere in 0.01-50 GHz. The same high-Q input causes the large band-edge ripple.

2. EDIT: add DC-blocked resistive shunt feedback RF-CF from the shared drain n2 to the NMOS gate n1. It de-Qs the input and output, gives a broadband real input impedance, and loads the output. That fixes the marginal mu_wide and flattens the gain. The bias networks are unchanged.

```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n2 n1 VSS VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
R RF n2 n7
C CF n7 n1
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```

3. PREDICTION: mu_min_wide improves by about +0.1 to +0.2, from 0.974 to about 1.08-1.15, which would pass. S21 ripple improves by about 0.5 dB, and s11_max improves at the band edges by about 2 dB. Peak S21 drops about 0.5 dB, which the sizer can recover with gm inside 9.08 mA.
