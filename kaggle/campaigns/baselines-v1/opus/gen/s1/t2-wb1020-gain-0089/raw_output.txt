1. DIAGNOSIS
The binding failure is wideband stability, narrowly (mu_wide = 0.954). The output is very high-Q (s22_max = -3.3 dB). The current-reuse drain sees a series L2-C2 branch to ground, which is inductive and nearly lossless above its series resonance. Through the NM1 + PM1 Cgd (gates AC-tied via C1), that inductive drain load produces a negative-real Miller admittance jwCgd(1 + gm*Z_L) at the input. The gate inductor L1 resonating with Cgs adds gate-voltage gain, so mu dips below 1 out of band. Nothing resistive damps the load where L2 dominates.

2. EDIT: add a damping resistor R6 across L2 (n2 to n4). The bias is unchanged (C2 blocks DC). At high frequency the branch becomes about R6 to ground, which bounds the drain impedance, kills the inductive-load negative conductance, and lowers the output Q (better s22).
```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n2 n1 VSS VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
R R6 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```
3. PREDICTION: mu_min_wide_0.01-50GHz improves from 0.95 to about 1.15 (+0.2; it passes). s22_max improves by about 2-3 dB. s21 costs about 0.2-0.3 dB, offset by a flatter response.
