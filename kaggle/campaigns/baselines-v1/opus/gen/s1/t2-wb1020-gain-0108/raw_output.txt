1. DIAGNOSIS
The worst failure is mu_min_wide at 0.997, a marginal out-of-band stability shortfall; in-band mu is 1.21. The current-reuse stage uses a narrowband series L1-Cgs input resonance (s11 is -13.5 dB at f0 but -8.2 dB at the band edges). Its output is the high-impedance shared drain ro_n||ro_p with the reactive L2-C2 trap (s22_max -4.1 dB). Away from 1-2 GHz both ports are high-Q and nearly lossless, and the Cgd reverse path of NM1 and PM1 closes a loop, so mu falls just below 1. The topology has no broadband resistive loss element.

2. EDIT: add DC-blocked resistive shunt feedback RF-CF from the shared drain n2 to the NMOS gate n1. It provides frequency-independent loss at both ports, lowers the output impedance, and de-Qs the input. The published gate bias networks stay unchanged.

```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n2 n1 VSS VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
R RF n2 n7
C CF n7 n1
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```

3. PREDICTION: mu_min_wide improves by about +0.1 to +0.15, from 0.997 to about 1.1, which would pass. s22_max improves by about 3-5 dB. S21 drops about 0.3-0.5 dB at fixed gm, recoverable within the 8.55 mA cap. NF rises by about 0.1 dB at most.
