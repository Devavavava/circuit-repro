1. DIAGNOSIS
The worst failure is mu_min_wide at 0.998: an essentially marginal out-of-band stability shortfall, with s11_max also failing by a hair (-7.846 vs -7.847 dB). The input match comes from the narrowband series L1-Cgs resonance: s11 is -12.7 dB at f0 but only -7.85 dB at the 1/2 GHz edges. The output is the high-impedance shared drain with the reactive L2-C2 trap (s22_max -4.6 dB). Both ports are high-Q and nearly lossless out of band, so the Cgd reverse transmission pushes mu just below 1.

2. EDIT: add DC-blocked resistive shunt feedback RF-CF from the shared drain n2 to the NMOS gate n1. It provides broadband resistive loss at both ports, lowers both the input Q and the output impedance, and widens the input match. The published bias networks are unchanged.

```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n2 n1 VSS VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
R RF n2 n7
C CF n7 n1
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```

3. PREDICTION: mu_min_wide improves by about +0.1 to +0.15, from 0.998 to about 1.1, which would pass with margin. s11_max at the band edges improves by about 1.5-3 dB, to about -9.5 to -10.5 dB. S21 drops about 0.3-0.5 dB at fixed gm, which the 10.3 mA budget can recover.
