1. DIAGNOSIS
The worst failure is mu_min_wide (0.917), out of band, while in-band mu is only 1.03. The output is poorly loaded: s22_max is -3.7 dB, because the shared drain of the current-reuse pair is a high-impedance node (ro_n||ro_p) carrying the high-Q series L2-C2 trap. The input is the high-Q series L1-Cgs resonance. Cgd of NM1 and PM1 provides a reverse path. With both ports nearly lossless outside the band, mu falls below 1 somewhere in 0.01-50 GHz. The binding problem is the lack of any broadband dissipative element, not the device sizes.

2. EDIT: add DC-blocked resistive shunt feedback RF-CF from the shared drain n2 to the NMOS gate n1. The feedback makes the input and output impedances resistive and lossy across the whole band and lowers the output impedance (better S22). It also flattens the response. The published bias networks are unchanged.

```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n2 n1 VSS VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
R RF n2 n7
C CF n7 n1
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```

3. PREDICTION: mu_min_wide improves by about +0.15 to +0.2, from 0.917 to about 1.08-1.12, which would pass. s22_max improves by about 4-6 dB, to about -8 to -10 dB. S21 drops about 0.3-0.6 dB at fixed current; there is about 0.1 dB of Idd headroom and the sizer can trade for it. NF changes by +0.1 dB at most.
