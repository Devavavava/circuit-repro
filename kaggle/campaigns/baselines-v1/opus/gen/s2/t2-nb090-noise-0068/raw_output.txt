1. DIAGNOSIS
The binding constraint is broadband stability (mu over 0.01-50 GHz = 0.87). Even at 900 MHz, mu is only 1.009 and k is 1.02, so the circuit sits right on the stability edge. The inverter's combined Cgd (NM1 and PM1) couples a weakly loaded, reactive output node back to the input. The output node is the L2 tank to AC ground through C2, and s22 of -4.2 dB shows it is weakly loaded and reactive. The input is a high-Q series resonance of L1 with the large gate capacitance. Away from 900 MHz, the output impedance turns inductive, Cgd turns it into negative gate conductance, and the undamped L1 loop lets the input reflection exceed 1. Gain is also 0.6 dB short, so lossy fixes in the signal path are expensive.

2. EDIT: put a damping resistor RD in parallel with the gate inductor L1. Near 900 MHz, RD is sized well above w*L1, so most of the signal still goes through L1. Out of band, especially at multi-GHz, w*L1 is far above RD, so RD sets a resistive source impedance at the gate and the negative-resistance input resonance is damped.
```netlist
C C4 VIN1 n0
L L1 n0 n1
R RD n0 n1
NMOS NM1 n2 n1 VSS VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```
3. PREDICTION: mu_min_wide_0.01-50GHz improves from 0.87 to about 1.02-1.1 (+0.15 to +0.2), and in-band mu also rises to about 1.1. The in-band cost is about 0.1-0.3 dB of NF and s21.
