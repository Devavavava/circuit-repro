1. DIAGNOSIS
NF is 2.46 dB against a 2.29 dB cap. With no source degeneration, the real part of the input impedance has to come from lossy elements, mainly the gate bias feed resistors R2/R5 and parasitic resistance. That resistive termination adds its noise directly to the input.
mu and k are about 1.00, so there is no room to buy NF with more gain or a higher-Q match.

2. EDIT: inductive source degeneration on NM1
Add LS from the NM1 source to VSS. This gives a noiseless real input resistance (gm*LS/Cgs) that resonates with L1 and Cgs at 900 MHz. The bias resistors can then become large and stop setting the match. The series feedback also improves the stability margin.

```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n2 n1 n8 VSS
L LS n8 VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```

3. PREDICTION
NF improves from 2.46 dB to about 2.0-2.1 dB (about 0.4 dB better).
Secondary effects:
- s11 holds at -8 dB or better.
- mu rises a little above 1.
