1. DIAGNOSIS
s11_max_db is -3.0 dB. NM1's gate goes straight to the port through a DC block, so the input is capacitive (Cgs plus the Miller Cgd). The only real part is the bias feed R2, which the NF cap (1.372 dB, spent) forbids lowering. There is no inductor to resonate Cgs and no noiseless real part.
The mismatch also makes s21 4.8 dB short.
mu_min_wide is 0.81 because stage 2 is a TITO configuration (series inductor L2 on its gate, L3 tank on its drain, coupled through Cgd).

2. EDIT: gate inductor plus source-degeneration inductor on NM1, cascodes on both stages, interstage series L removed
This keeps 4 inductors.

```netlist
C C1 VIN1 n0
L LG n0 n1
NMOS NM1 n8 n1 n9 VSS
L LS n9 VSS
NMOS NM4 n2 VDD n8 VSS
L L1 VDD n2
C C2 n2 n5
NMOS NM2 n10 n5 VSS VSS
NMOS NM5 n6 VDD n10 VSS
L L3 VDD n6
C C3 n6 VOUT1
R R1 VDD n7
NMOS NM3 n7 n7 VSS VSS
R R2 n7 n1
R R3 n7 n5
```

3. PREDICTION
s11_max_db improves from -3.0 dB to about -10 dB (about 7 dB better).
Secondary effects:
- s21 rises by about 4 to 5 dB.
- mu_min_wide rises above 1.
- NF stays roughly flat.
