1. DIAGNOSIS
s11_max_db is -3.1 dB. The input is a bare common-source gate behind a DC block, so it is capacitive (Cgs plus the Miller Cgd) with no controllable real part. The only resistive part is the bias feed R2, and the NF cap (1.357 dB, already spent) prevents using it to match.
The unmatched gate also loses voltage gain, so s21 is 4 dB short.
mu_min_wide is 0.82 because stage 2 is a TITO configuration (series inductor L2 on its gate, L3 tank on its drain).

2. EDIT: series gate inductor plus source degeneration on NM1, cascodes on both stages, interstage series L removed
This keeps 4 inductors.

```netlist
C C1 VIN1 n0
L LG n0 n1
NMOS NM1 n8 n1 n9 VSS
L LS n9 VSS
NMOS NM4 n2 VDD n8 VSS
L L1 VDD n2
C C2 n2 n5
NMOS NM2 n10 n5 VSS VSS
NMOS NM5 n6 VDD n10 VSS
L L3 VDD n6
C C3 n6 VOUT1
R R1 VDD n7
NMOS NM3 n7 n7 VSS VSS
R R2 n7 n1
R R3 n7 n5
```

3. PREDICTION
s11_max_db improves from -3.1 dB to about -10 dB (about 7 dB better).
Secondary effects:
- s21 rises by about 4 dB.
- mu_min_wide rises above 1.
- NF stays roughly flat.
