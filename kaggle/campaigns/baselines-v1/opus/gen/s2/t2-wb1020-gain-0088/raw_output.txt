1. DIAGNOSIS
The binding constraint is broadband stability (mu over 0.01-50 GHz = 0.72). s21 is also 2.4 dB short. A single common-source device NM1 drives a shunt-peaked load (L1 + R2) that becomes inductive above the band. Cgd couples this inductive drain impedance back to the gate as negative conductance, the Miller-inductive mechanism. At those frequencies the feedback resistor R1 is bypassed by Cgd. The same Cgd Miller effect loads the input and limits gain-bandwidth, so at the current cap the sizer cannot reach 11.6 dB without destabilizing further.

2. EDIT: cascode NM2 (gate at VDD) between NM1 and the shunt-peaked load, with R1 still from the output node to the gate. NM1's drain sees 1/gm2, which is low and resistive. This removes the internal negative-resistance mechanism, shrinks the Miller capacitance, and raises output resistance, so the gain set by the feedback goes up.
```netlist
C C1 VIN1 n1
R R1 n1 n2
NMOS NM1 n8 n1 VSS VSS
NMOS NM2 n2 VDD n8 VSS
L L1 VDD n3
R R2 n3 n2
C C2 n2 VOUT1
```
3. PREDICTION: mu_min_wide_0.01-50GHz improves from 0.72 to about 1.0-1.15 (+0.3 to +0.4). s21 improves by about 1.5-2 dB, to roughly 11 dB.
