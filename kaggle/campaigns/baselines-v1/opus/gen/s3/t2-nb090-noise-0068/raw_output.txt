1. DIAGNOSIS
The binding metric is mu_min_wide = 0.874, and in-band mu is barely 1.009. The current-reuse stage has an inductive gate termination (series L1) and an output n2 that is nearly undamped: ro_n||ro_p plus the L2-C2 branch, which is inductive above its series resonance (s22 -4.3 dB).
These two terminations, coupled through Cgd_n + Cgd_p (s12 -25.9 dB), give the tuned-gate/tuned-drain negative-resistance condition, both just around f0 and strongly out of band. The sizer had to shave gain to keep mu_min at 1.0, which is why s21 also misses (14.47 vs >=15.05 dB).

2. EDIT: add resistive shunt feedback R6 from the output n2 to the NMOS gate n1, and self-bias NM1 through it.
- This removes the NMOS mirror reference R1/NM3/R2; its current goes to the core gm.
- R6 adds broadband loss linking both ports, so the out-of-band negative conductance disappears and |s22| drops.
- L1 still resonates the gate capacitance for the 900 MHz match.
```netlist
* lna-a2-current-reuse edit: resistive shunt feedback R6 (out->NMOS gate), NM1 self-biased via R6
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n2 n1 VSS VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R6 n2 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```
3. PREDICTION
- Binding metric: mu_min_wide improves from 0.874 to ~1.1-1.25 (about +0.3). In-band mu rises to ~1.3.
- s21: changes by roughly -0.5 to +0.5 dB. The reclaimed mirror current and the relaxed stability trade should let it reach ~15 dB.
- NF: rises ~+0.1 dB.
