1. DIAGNOSIS
The binding metric is mu_min_wide = 0.997, just below 1, with in-band mu at 1.21. The current-reuse inverter has no resistive damping: an inductive gate termination (series L1) and an output n2 loaded only by ro_n||ro_p and the L2-C2 branch, which is inductive above its series resonance (s22_max -4.1 dB).
Through Cgd_n + Cgd_p (s12 -26.6 dB), this tuned-gate/tuned-drain arrangement gives marginal negative resistance out of band. The sizer cannot drop gain to recover it because s21 sits exactly at its gate (12.188 vs 12.189 dB).

2. EDIT: add resistive shunt feedback R6 from the output n2 to the NMOS gate n1, and self-bias NM1 through it.
- This removes the NMOS mirror reference R1/NM3/R2 and returns its current to the core.
- R6 adds broadband loss linking the ports, which removes the out-of-band negative conductance and lowers |s22|.
```netlist
* lna-a2-current-reuse edit: resistive shunt feedback R6 (out->NMOS gate), NM1 self-biased via R6
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n2 n1 VSS VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R6 n2 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```
3. PREDICTION
- Binding metric: mu_min_wide improves from 0.997 to ~1.2-1.3 (about +0.2).
- s22_max: improves by ~3-4 dB.
- s21: changes by roughly -0.3 to +0.5 dB.
- NF: rises ~+0.1 dB (0.03 dB of margin, partly offset by removing R2's gate noise).
