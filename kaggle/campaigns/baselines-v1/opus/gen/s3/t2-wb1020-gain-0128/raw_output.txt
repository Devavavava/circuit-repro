1. DIAGNOSIS
The binding metric is mu_min_wide = 0.917, and in-band mu is 1.03. The inverter LNA is a single undamped gain node:
- Inductive source termination at the gate (series L1).
- An output n2 loaded by ro_n||ro_p and the L2-C2 branch, which is inductive above its series resonance (s22_max -3.67 dB).
Coupled by Cgd_n + Cgd_p (s12 -25.5 dB), this is a tuned-gate/tuned-drain negative-resistance configuration out of band. The sizer cannot reduce gain or Q because s21, NF, s11 and Idd are all pinned at their gates.

2. EDIT: add resistive shunt feedback R6 from the output n2 to the NMOS gate n1, and self-bias NM1 through it.
- This removes the NMOS mirror reference R1/NM3/R2 (its current goes back to the core).
- R6 is broadband resistive loss linking the ports, so it eliminates the out-of-band negative conductance and lowers |s22|.
- L1 still matches in band.
```netlist
* lna-a2-current-reuse edit: resistive shunt feedback R6 (out->NMOS gate), NM1 self-biased via R6
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n2 n1 VSS VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R6 n2 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```
3. PREDICTION
- Binding metric: mu_min_wide improves from 0.917 to ~1.15-1.3 (about +0.25).
- s22_max: improves by ~4 dB.
- s21: changes by roughly -0.5 to +0.5 dB.
- NF: rises ~+0.1 to +0.15 dB.
