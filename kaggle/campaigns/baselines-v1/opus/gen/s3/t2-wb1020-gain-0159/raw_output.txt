1. DIAGNOSIS
The binding metric is mu_min_wide = 0.932, with in-band mu only 1.06. Above the band, the inverter's gate sees the inductive series L1 and its drain sees the L2-C2 branch, which turns inductive above series resonance. The output is otherwise only ro_n||ro_p (s22_max -3.8 dB).
Cgd_n + Cgd_p (s12 -25.5 dB) close a tuned-gate/tuned-drain loop with negative port resistance. With s21, NF and Idd pinned at their gates, sizing has no damping knob left.

2. EDIT: add resistive shunt feedback R6 from the output n2 to the NMOS gate n1, and self-bias NM1 through it.
- This removes the NMOS mirror reference R1/NM3/R2.
- It gives broadband resistive damping between the ports.
- L1 continues to resonate the gate capacitance for the in-band match.
```netlist
* lna-a2-current-reuse edit: resistive shunt feedback R6 (out->NMOS gate), NM1 self-biased via R6
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n2 n1 VSS VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R6 n2 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```
3. PREDICTION
- Binding metric: mu_min_wide improves from 0.932 to ~1.15-1.3 (about +0.25).
- s22_max: improves by ~4 dB.
- s21: changes by roughly -0.5 to +0.5 dB.
- NF: rises ~+0.1 dB.
