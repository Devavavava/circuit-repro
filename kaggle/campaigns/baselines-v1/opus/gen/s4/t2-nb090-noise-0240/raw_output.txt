1. DIAGNOSIS
The binding constraint is broadband stability (mu_min over 0.01-50 GHz = 0.79). In-band mu is pinned at 1.005 and S21 is 0.45 dB short. The un-cascoded current-reuse stage has Cgd feedback from n2 to the input through both NM1 and PM1 (PM1's gate is AC-tied to the input via C1), so S12 is only -26 dB and k_f0 = 1.03.

L2, AC-grounded by C2, is an inductive load below its resonance, where Miller feedback presents a negative conductance at the gate. The lossless input (series L1, no degeneration) does not damp it, so off-resonance mu collapses to 0.79. In band the same mechanism caps gain at the mu = 1 boundary, which is why S21 is short.

2. EDIT: build an inductively-degenerated cascode current-reuse stage. The NMOS cascode NM4 (gate to VDD) isolates the inductive load from the gate, and the source inductor L3 provides a noiseless real input resistance in place of the Miller-derived one.
```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n7 n1 n8 VSS
L L3 n8 VSS
NMOS NM4 n2 VDD n7 VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```
3. PREDICTION: mu_min_wide (binding) improves from 0.79 to ~1.05-1.1 (+0.3). In-band mu rises to ~1.3, S21 gains ~1-2 dB (clearing 14.9 dB), and NF stays ~2.1-2.2 dB.
