1. DIAGNOSIS
The binding constraint is s11_max_db (-3.7 dB against a -7.85 dB gate). s21 is also 5.7 dB short.
- The NM1 gate is driven directly through DC-block C1, so at 900 MHz Zin is a capacitive Cgs1 in parallel with bias R2. There is no element that creates a noiseless 50-ohm real part and no inductor that resonates out Cgs. With NF pinned at 1.5 dB, the optimizer cannot lower R2 to make a real part, so the input stays badly mismatched.
- The mismatch also costs several dB of S21. The circuit misses the voltage gain that a resonant input network would give.

2. EDIT: inductive source degeneration plus a series gate inductor on NM1, and a cascode on stage 1
- L4 (gate) and L5 (source) give Re{Zin} = wT*Ls = 50 ohm and resonate Cgs1 at 900 MHz. This is a noiseless match with input Q voltage gain.
- L2 is removed to stay within 4 inductors. C2 couples directly and L1 resonates the NM2 gate capacitance.
- Cascode NM4 raises the stage-1 tank impedance and the gain.
```netlist
C C1 VIN1 n0
L L4 n0 n1
NMOS NM1 n8 n1 n9 VSS
L L5 n9 VSS
NMOS NM4 n2 VDD n8 VSS
L L1 VDD n2
C C2 n2 n5
NMOS NM2 n6 n5 VSS VSS
L L3 VDD n6
C C3 n6 VOUT1
R R1 VDD n7
NMOS NM3 n7 n7 VSS VSS
R R2 n7 n1
R R3 n7 n5
```
3. PREDICTION
s11_max_db should improve by about 8 dB, from -3.7 to about -11 dB. s21 should rise by about 5 dB (match recovery plus input-Q boost plus cascode), to about 19 dB. NF should stay at about 1.4-1.5 dB.
