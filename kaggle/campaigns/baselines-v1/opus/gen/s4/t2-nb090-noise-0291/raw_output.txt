1. DIAGNOSIS
The binding constraint is s11_max_db (-3.6 dB against a -7.9 dB gate). s21 is also 4.6 dB short.
- Stage 1 receives the input through C1 directly on the NM1 gate, so Zin at 900 MHz is a high-Q capacitive Cgs1 in parallel with bias R2.
- No element synthesizes a noiseless 50-ohm real part, and nothing resonates Cgs. Because NF is held at 1.48 dB, the sizer cannot use a small R2 to make a real part, so the input stays badly mismatched. That mismatch, plus the missing input-network voltage gain, also explains the S21 shortfall.

2. EDIT: inductive source degeneration plus a series gate inductor on NM1, and a cascode on stage 1
- L4 (Lg) and L5 (Ls) set Re{Zin} = wT*Ls = 50 ohm and resonate Cgs1 at f0. This is a noiseless match whose input Q also gives voltage gain.
- L2 is dropped to stay within the 4-inductor screen. C2 couples directly and L1 tunes the stage-1 drain plus the NM2 gate.
- Cascode NM4 raises stage-1 gain and isolation.
```netlist
C C1 VIN1 n0
L L4 n0 n1
NMOS NM1 n8 n1 n9 VSS
L L5 n9 VSS
NMOS NM4 n2 VDD n8 VSS
L L1 VDD n2
C C2 n2 n5
NMOS NM2 n6 n5 VSS VSS
L L3 VDD n6
C C3 n6 VOUT1
R R1 VDD n7
NMOS NM3 n7 n7 VSS VSS
R R2 n7 n1
R R3 n7 n5
```
3. PREDICTION
s11_max_db should improve by about 7-8 dB, from -3.6 to about -11 dB. s21 should rise by about 4-5 dB, to about 18.5 dB. NF should stay at about 1.4 dB.
