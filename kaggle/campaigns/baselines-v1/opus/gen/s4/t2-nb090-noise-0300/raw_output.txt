1. DIAGNOSIS
The binding constraint is input match (S11 = -3.0 dB against -7.86 dB), with S21 short as well (14.0 against 18.8 dB). The input network is just DC-block C1 into the gate of NM1, shunted by the bias feed R2. The port sees C1 in series with Cgs, a nearly lossless capacitor, so |S11| is near 0 dB.

The only resistive element that could create a real part is R2, and it would add input-referred thermal noise; NF is already at its limit (1.372 against 1.372). The resulting ~3 dB mismatch loss is a large part of the gain shortfall. Stage 2 (series gate L2 and the L1 tank on its gate, tuned drain L3, Cgd) forms a tuned-gate/tuned-drain loop that also sets mu over 0.01-50 GHz to 0.81.

2. EDIT: build an inductively-degenerated cascode input stage.
- Add Lg in series with the gate and Ls from the NM1 source to ground, for a noiseless 50-ohm real part.
- Remove the interstage L2 (keeping 4 inductors and removing the tuned gate of stage 2).
- Cascode both stages, with their cascode gates tied to VDD.
```netlist
C C1 VIN1 n0
L Lg n0 n1
NMOS NM1 n8 n1 n3 VSS
L Ls n3 VSS
NMOS NM4 n2 VDD n8 VSS
L L1 VDD n2
C C2 n2 n5
NMOS NM2 n9 n5 VSS VSS
NMOS NM5 n6 VDD n9 VSS
L L3 VDD n6
C C3 n6 VOUT1
R R1 VDD n7
NMOS NM3 n7 n7 VSS VSS
R R2 n7 n1
R R3 n7 n5
```
3. PREDICTION: s11_max_db (binding) improves from -3.0 dB to ~-12 dB (about 9 dB better). S21 rises by ~5-7 dB to about 19-21 dB, NF stays ~1.3-1.4 dB, and mu_min_wide rises above 1.
