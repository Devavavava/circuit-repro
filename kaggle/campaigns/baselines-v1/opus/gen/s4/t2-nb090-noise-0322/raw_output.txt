1. DIAGNOSIS
The binding constraint is s11_max_db (-3.1 dB against a -7.9 dB gate). s21 is also 4 dB short.
- The first-stage gate is driven directly through C1, so Zin at 900 MHz is a capacitive Cgs1 in parallel with bias R2. There is no noiseless real part and no resonance of Cgs. Because NF (1.34 dB) is at its edge, the optimizer cannot use R2 to create a real part, so the input is nearly reflective.
- The resulting mismatch loss (about 2-3 dB) and the missing input-Q voltage gain explain the gain shortfall.

2. EDIT: inductively degenerated input (Lg+Ls) on NM1, plus a cascode on stage 1
- L4 and L5 create Re{Zin} = wT*Ls at 50 ohm and cancel Cgs1 at f0. This is a noiseless match with voltage gain from the input network Q.
- L2 is removed to respect the 4-inductor screen. L1 tunes the stage-1 drain plus the NM2 gate capacitance.
- Cascode NM4 raises the gain and isolation.
```netlist
C C1 VIN1 n0
L L4 n0 n1
NMOS NM1 n8 n1 n9 VSS
L L5 n9 VSS
NMOS NM4 n2 VDD n8 VSS
L L1 VDD n2
C C2 n2 n5
NMOS NM2 n6 n5 VSS VSS
L L3 VDD n6
C C3 n6 VOUT1
R R1 VDD n7
NMOS NM3 n7 n7 VSS VSS
R R2 n7 n1
R R3 n7 n5
```
3. PREDICTION
s11_max_db should improve by about 8 dB, from -3.1 to about -11 dB. s21 should rise by about 4 dB, to about 18.5-19 dB. NF should stay at about 1.3 dB.
