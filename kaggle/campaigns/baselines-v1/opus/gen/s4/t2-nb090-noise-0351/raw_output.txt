1. DIAGNOSIS
The binding constraint is s11_max_db (-3.46 dB against a -7.92 dB gate). s21 is also 4.9 dB short.
- The input is C1 straight to the NM1 gate, so at 900 MHz Zin is a capacitive Cgs1 in parallel with bias R2. There is no noiseless real part and no Cgs resonance.
- With NF pinned at 1.43 dB, R2 must stay large, so the input is strongly mismatched. That wastes about 2 dB of S21 and loses the voltage gain a resonant input network would provide.

2. EDIT: series gate inductor plus source-degeneration inductor on NM1, and a cascode on stage 1
- L4 and L5 make Re{Zin} = wT*Ls = 50 ohm and resonate Cgs1 at f0, which is a noiseless match with input-Q gain.
- L2 is dropped to stay within 4 inductors. L1 tunes the interstage node (stage-1 drain plus the NM2 gate).
- Cascode NM4 raises stage-1 gain and isolation.
```netlist
C C1 VIN1 n0
L L4 n0 n1
NMOS NM1 n8 n1 n9 VSS
L L5 n9 VSS
NMOS NM4 n2 VDD n8 VSS
L L1 VDD n2
C C2 n2 n5
NMOS NM2 n6 n5 VSS VSS
L L3 VDD n6
C C3 n6 VOUT1
R R1 VDD n7
NMOS NM3 n7 n7 VSS VSS
R R2 n7 n1
R R3 n7 n5
```
3. PREDICTION
s11_max_db should improve by about 7-8 dB, from -3.5 to about -11 dB. s21 should rise by about 4-5 dB, to about 19 dB. NF should stay at about 1.3-1.4 dB.
