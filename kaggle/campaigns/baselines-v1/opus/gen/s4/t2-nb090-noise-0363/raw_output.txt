1. DIAGNOSIS
The binding constraint is s11_max_db (-4.07 dB against a -7.91 dB gate). The NM1 gate is driven straight through C1, so the 900 MHz input impedance is Cgs1 in parallel with bias R2: capacitive, with no noiseless real part and no resonance. NF (1.67 dB) and gain (13.08 dB) are both at their edges, so the sizer cannot lower R2 to create a resistive input without breaking NF, and the match stays near -4 dB.

2. EDIT: series gate inductor plus source-degeneration inductor on NM1, and a cascode on stage 1
- L4 and L5 make Re{Zin} = wT*Ls = 50 ohm and resonate Cgs1 at f0, which is a noiseless match.
- L2 is removed to stay within 4 inductors. L1 tunes the interstage.
- Cascode NM4 adds gain and isolation, so the input match is independent of the load.
```netlist
C C1 VIN1 n0
L L4 n0 n1
NMOS NM1 n8 n1 n9 VSS
L L5 n9 VSS
NMOS NM4 n2 VDD n8 VSS
L L1 VDD n2
C C2 n2 n5
NMOS NM2 n6 n5 VSS VSS
L L3 VDD n6
C C3 n6 VOUT1
R R1 VDD n7
NMOS NM3 n7 n7 VSS VSS
R R2 n7 n1
R R3 n7 n5
```
3. PREDICTION
s11_max_db should improve by about 7 dB, from -4.1 to about -11 dB. s21 should rise by about 2-3 dB. NF should stay at about 1.6 dB.
