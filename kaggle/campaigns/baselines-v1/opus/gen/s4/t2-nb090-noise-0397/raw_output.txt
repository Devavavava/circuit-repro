1. DIAGNOSIS
The binding constraint is input match (S11 = -2.7 dB against -7.87 dB), and S21 is also short (14.7 against 16.5 dB). The input is C1 straight onto the gate of NM1, with R2 as the only shunt element. The input impedance is therefore essentially C1 in series with Cgs, purely reactive, so |S11| is close to 0 dB.

The only resistive lever is R2, which is a noise source right at the input; NF is pinned at its limit (1.2985 against 1.2984). The large mismatch loss (~3-4 dB) is the main reason S21 is short. Stage 2's tuned gate (series L2 plus the L1 tank) and tuned drain (L3), coupled through Cgd, form a TGTD loop that sets mu over 0.01-50 GHz to 0.74.

2. EDIT: build an inductively-degenerated cascode input stage.
- Add a series gate inductor Lg and a source-degeneration inductor Ls, giving a noiseless real input of gm*Ls/Cgs resonated at 900 MHz.
- Remove the interstage L2 to stay within 4 inductors and break stage 2's tuned gate.
- Cascode both stages, with their cascode gates tied to VDD.
```netlist
C C1 VIN1 n0
L Lg n0 n1
NMOS NM1 n8 n1 n3 VSS
L Ls n3 VSS
NMOS NM4 n2 VDD n8 VSS
L L1 VDD n2
C C2 n2 n5
NMOS NM2 n9 n5 VSS VSS
NMOS NM5 n6 VDD n9 VSS
L L3 VDD n6
C C3 n6 VOUT1
R R1 VDD n7
NMOS NM3 n7 n7 VSS VSS
R R2 n7 n1
R R3 n7 n5
```
3. PREDICTION: s11_max_db (binding) improves from -2.7 dB to ~-12 dB (about 9 dB better). S21 rises by ~5-7 dB to about 20 dB, NF stays ~1.2-1.3 dB, and mu_min_wide rises above 1.
