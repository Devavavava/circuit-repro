1. DIAGNOSIS
The binding constraint is mu_min_wide (0.886).
- In the current-reuse inverter, Cgd of both NMOS and PMOS couples the shared drain n2 back to the AC-tied gates, giving a large reverse transmission (S12 about -26.8 dB).
- The input is series L1 into a capacitive gate, and the output is the reactive L2-C2/drain tank behind DC-block C3. Out of band both ports become nearly lossless (|S11| and |S22| approach 1), so the remaining S12*S21 pushes mu below 1.
- Every other metric is at its edge (NF, gain, Idd), so there is no room to add resistive loss without breaking NF or gain.

2. EDIT: NMOS cascode in the current-reuse stack
Add NM2 (gate to VDD) between n2 and the NM1 drain. This shields the NMOS Cgd from the output, which lowers S12, and raises the output resistance, which adds gain headroom. The cascode adds no resistive noise.
```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n7 n1 VSS VSS
NMOS NM2 n2 VDD n7 VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```
3. PREDICTION
mu_min_wide should rise from 0.89 to about 1.05-1.1 (+0.2) and pass. S12 should improve by about 6-10 dB, and s21 by about 1 dB.
