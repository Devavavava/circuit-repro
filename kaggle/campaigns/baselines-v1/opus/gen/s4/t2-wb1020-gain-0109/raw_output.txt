1. DIAGNOSIS
The binding constraint is broadband stability (mu_min over 0.01-50 GHz = 0.92). In-band mu = 1.0006 and k_min = 1.002, so the circuit is on the stability boundary even in band. In the un-cascoded current-reuse stage, the output n2 feeds back to the input through the Cgd of NM1 and PM1 (PM1's gate is AC-coupled by C1), so S12 = -26 dB and S22 rises to -2.6 dB at the band edge.

The L2 tank (AC-grounded by C2) is inductive below resonance, where Miller feedback gives the gate a negative conductance. The input (series L1, no degeneration) has no resistance to damp it, so mu falls below 1 out of band. With NF_max, S21 and Idd all at zero margin, the sizer cannot back off the gain.

2. EDIT: cascode NM1 (cascode gate to VDD) to cut the inductive-load -> gate Miller path, and add a source-degeneration inductor L3 on NM1 for a noiseless real input resistance (inductively-degenerated cascode current-reuse stage).
```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n7 n1 n8 VSS
L L3 n8 VSS
NMOS NM4 n2 VDD n7 VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```
3. PREDICTION: mu_min_wide (binding) improves from 0.92 to ~1.1 (+0.2). In-band mu rises to ~1.2-1.3, S12 improves by ~10 dB, and S21 gains ~1 dB.
