1. DIAGNOSIS
The binding constraint is nf_max_db (2.50 against a 2.04 dB gate over 0.8-2.4 GHz).
- The current-reuse inverter has no noiseless way to make a real input resistance. Apart from gate resistance, the only real part at the gate comes from the bias feed resistors R2 (NMOS gate) and R5 (PMOS gate through C1). Matching s11 to about -9 dB therefore means terminating the input in physical resistors, whose thermal noise adds directly. A shunt-resistor match sets an NF floor close to 3 dB at the band edges.
- The series L1 + Cgs resonance also only matches near the center, so at 0.8 and 2.4 GHz the match and the noise both degrade.

2. EDIT: resistive shunt feedback (resistive-feedback inverter LNA)
Add Rf from the output n2 back to the NMOS gate n1, through a DC-block cap so the published bias is kept. The gates are AC-tied by C1, so this is feedback around the whole inverter.
- The input resistance becomes about Rf/(1 + gm_total*Rout). This is a broadband real part produced by feedback, not by a grounded resistor, so its noise is divided by the loop gain.
- R2 and R5 can be made large, which removes their noise.
- The feedback also flattens the match over the 3:1 band and damps the output, which helps mu_wide (0.90).
```netlist
C C4 VIN1 n0
L L1 n0 n1
NMOS NM1 n2 n1 VSS VSS
C C1 n1 n3
PMOS PM1 n2 n3 VDD VDD
L L2 n2 n4
C C2 n4 VSS
C C3 n2 VOUT1
R R6 n2 n8
C C5 n8 n1
R R1 VDD n5
NMOS NM3 n5 n5 VSS VSS
R R2 n5 n1
PMOS PM2 n6 n6 VDD VDD
R R4 n6 VSS
R R5 n6 n3
```
3. PREDICTION
nf_max_db should improve by about 0.5-0.7 dB, from 2.50 to about 1.85-2.0 dB. s11_max should improve by about 1-2 dB, and mu_min_wide should rise to about 1.0 or above.
