=== WORKED EXAMPLE: repairing a wideband (multi-octave) LNA ===
A wideband LNA that relies only on reactive (L/C) input matching cannot hold a low S11 across a decade of frequency: a series/shunt L-C network is inherently narrowband. The standard fix is RESISTIVE SHUNT FEEDBACK -- add a feedback resistor from the amplifier's output/drain node back to the input gate node. This makes the input impedance broadband and largely real (Zin ~ Rf/(1+gm*Rd)), flattening the return loss across the whole band, at the cost of a little gain/NF. Example fix (topology only, generic device):
```netlist
C C1 VIN1 g
NMOS M1 d g VSS VSS
NMOS M2 o VDD d VSS
R Rd VDD o
R Rf o g
C C2 o VOUT1
```
Here `R Rf o g` is the feedback resistor from output `o` to input gate `g` -- the broadband-matching element a purely reactive network lacks. Apply the technique that FITS the failure below; do not copy this example verbatim.
