```netlist
* Variant 1: Common-source topology with source inductor and gate bias
* Replaces common-gate with common-source, adds source inductor for input match
* Gate bias through resistor Rg, source inductor Ls for inductive degeneration
C C1 VIN1 g1
R Rg g1 n1
NMOS NM1 n2 n1 s1 VSS
L Ls s1 VSS
L L2 VDD n2
C C2 n2 VOUT1
R R1 VDD n3
NMOS NM3 n3 n3 VSS VSS
R R2 n3 s1
C Cbyp n1 VSS
```

```netlist
* Variant 2: Cascode structure with PMOS drain load
* Adds PMOS cascode transistor PM2 to improve gain and output impedance
* Maintains common-gate configuration for NM1
C C1 VIN1 n0
L L1 n0 VSS
NMOS NM1 n2 n1 n0 VSS
PMOS PM2 n2 g2 VDD VDD
L L2 VDD g2
C C2 n2 VOUT1
R R1 VDD n3
NMOS NM3 n3 n3 VSS VSS
R R2 n3 n1
C Cbyp n1 VSS
```

```netlist
* Variant 3: Resonant drain load with parallel LC tank
* Replaces simple drain inductor L2 with parallel LC tank (L2+C2tank)
* Adds capacitor C2tank in parallel with L2 for frequency-specific loading
C C1 VIN1 n0
L L1 n0 VSS
NMOS NM1 n2 n1 n0 VSS
L L2 n2 n4
C C2tank n4 VDD
```
