The binding constraint is the noise figure (nf_max_db), which is too high due to the noise contribution from the biasing network and the current-reuse structure. The original design uses a diode-connected NMOS (NM3) and PMOS (PM2) for biasing, which introduces additional noise into the signal path. This is exacerbated by the current-reuse topology, which can amplify noise from the biasing network and the load network (L2+C2). The noise figure is also affected by the high impedance of the current mirror and the lack of proper noise grounding.

To address this, the biasing network is restructured to use a direct NMOS (NM3) connected to the input node (n0) instead of the ground node (VSS), which provides a lower-noise path and better noise grounding. Additionally, the PMOS (PM2) is connected to the output node (n4) instead of the ground node, which helps in reducing the noise contribution from the current mirror and improves the noise figure by providing a more stable and lower-noise biasing path. The load network is also adjusted by connecting the PMOS (PM2) to the output node, which helps in improving the noise performance by reducing the noise coupling from the biasing network to the signal path.
