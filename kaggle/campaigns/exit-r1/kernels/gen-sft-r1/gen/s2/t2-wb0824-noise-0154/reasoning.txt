The failure is due to insufficient stability margin (`mu_min_wide_0.01-50GHz`) caused by the current-reuse topology's feedback loop and the shared DC path between the NMOS and PMOS stages. The NMOS and PMOS transistors are both connected to the same DC path via the shared node `n3`, which introduces a parasitic feedback path that destabilizes the amplifier over a wide frequency range. This is exacerbated by the lack of isolation between the input and output nodes, as the output is directly coupled to the NMOS stage through the tuned load `L2+C2`.

To address this, I restructured the topology to eliminate the shared DC path and improve isolation. The NMOS and PMOS stages are now decoupled, with the NMOS transistor feeding into a separate node (`n2`) that is not directly connected to the PMOS stage's DC path. The output is now coupled through a separate inductor (`L3`), reducing parasitic feedback and improving stability. Additionally, the current mirror (`NM3` and `R1`) is now connected to a dedicated node (`n7`), ensuring a stable biasing network without interfering with the signal path.
