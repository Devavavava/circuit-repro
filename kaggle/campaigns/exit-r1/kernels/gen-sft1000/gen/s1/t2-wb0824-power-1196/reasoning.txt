The noise figure (nf_max_db) is the binding constraint, and it is failing due to the noise contribution from the input transistor NM1 and the biasing network. The noise performance is being degraded by the current mirror NM3 and the resistive biasing network (R1, R2), which introduce additional noise into the signal path. The structure lacks a noise-shaping or noise-isolating element at the input stage, leading to a higher-than-allowed noise floor.

To address this, I added a noise-canceling capacitor (ZC1) between the internal node n2 and the bias reference node n5. This capacitor provides a low-impedance path for high-frequency noise from the bias network to ground, effectively decoupling the input signal from the noise sources in the biasing network. This change reduces the noise contribution from the biasing network to the signal path, thereby improving the noise figure.
