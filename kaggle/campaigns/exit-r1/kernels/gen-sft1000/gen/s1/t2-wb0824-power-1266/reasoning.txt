The failure is primarily due to noise figure (nf_max_db) exceeding the specification, despite other metrics being within bounds. This suggests a noise bottleneck in the signal path, likely originating from the transistors or the load network. The original topology uses a current-reuse push-pull configuration with a shared DC path and a tuned load (L2+C2). While this topology is effective for gain and linearity, it may not provide sufficient noise suppression at the target frequency, especially due to the shared DC path and the load configuration, which can introduce noise coupling or insufficient noise isolation.

To address this, I propose a structural change that isolates the signal path from the noise-generating components and introduces a more noise-optimized load configuration. The revised topology replaces the shared DC path with an independent DC path for the PMOS transistor, reducing noise coupling. Additionally, the load network is restructured to use a separate inductor (L3) and capacitor (C3) for the output, improving noise isolation and stability. The NMOS transistor is connected directly to the output, reducing noise contribution from the signal path.
