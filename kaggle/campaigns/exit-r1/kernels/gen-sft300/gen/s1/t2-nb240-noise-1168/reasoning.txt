The lack of additional phase-shifting elements or a more robust feedback structure exacerbates this issue, leading to instability.

This adds an additional phase-shifting element and helps stabilize the feedback loop, improving the stability margin across the band. Additionally, I add a capacitor (`C2`) between the output node (`n2`) and the internal node of the shunt inductor (`n3`), which helps in shaping the frequency response and enhancing phase margin. These changes structurally modify the feedback and output network to improve stability without compromising gain or noise performance.
