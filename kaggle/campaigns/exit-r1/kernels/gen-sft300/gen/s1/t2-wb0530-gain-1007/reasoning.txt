To address this, I added a second capacitor (ZC2) in parallel with the input DC-blocking capacitor (C4), connecting VDD to node n5. This provides an additional impedance path at the input, helping to improve the input matching over the wideband frequency range. This change enhances the S11 performance by better controlling the input impedance, especially at the higher frequencies where the original netlist struggled with matching.
