The noise figure (NF) is the binding constraint, and it is failing due to the noise contribution from the input transistor NM1 being too high. In the current topology, NM1 is a common-source (CS) stage with a DC-blocking capacitor C4 at the input and a resonant load (L2+C2) at the output. While this configuration helps in achieving a high gain and a good impedance match, it lacks sufficient noise suppression at the input stage. The noise from NM1 is directly amplified and contributes significantly to the overall noise figure, especially in a current-reuse configuration where the noise from the input transistor is not well attenuated.

To address this, I introduce a noise-cancelling feedback path from the output of the amplifier (n2) to the gate of a new NMOS transistor (ZN1), which is connected to a bias point (n5) and a new capacitor (ZC1) to the input node (n1). This feedback path helps in reducing the noise contribution from the input transistor by actively canceling out the noise at the input node. The new capacitor ZC1 provides a low-impedance path for noise at the input frequency, further helping in noise suppression. This change introduces a noise-cancelling mechanism that directly targets the noise figure, improving it without significantly affecting the gain or stability of the circuit.
