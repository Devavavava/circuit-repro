To address this, I propose a structural change that introduces a dedicated stability-enhancing feedback path and isolates the feedback network from the main signal path. This is achieved by replacing the shared DC path with a separate feedback node and adding a decoupling capacitor between the feedback node and ground. Additionally, a resistor is added between the feedback node and the input to suppress high-frequency oscillations. These changes improve the phase margin and suppress parasitic feedback, thereby increasing the stability margin across the entire band.
