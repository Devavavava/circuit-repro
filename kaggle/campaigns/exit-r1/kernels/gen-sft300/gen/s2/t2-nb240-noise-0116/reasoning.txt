Additionally, the input is DC-blocked by C4, which may limit the bandwidth and signal coupling at the operating frequency.

To address this, I propose a structural change that introduces a direct signal path from the input to the output, bypassing the shared DC path and enabling a stronger voltage gain. This is achieved by replacing the current-reuse structure with a common-gate configuration for the input stage, which allows for better signal transmission and gain. The PMOS transistor PM2 is reconnected to a new internal node (n6), and the NMOS transistor NM3 is replaced with a resistor (ZR1) to provide a stable reference point. The output coupling is improved by connecting the tuned LC network directly to the output node (VOUT1), and an additional inductor (ZL1) is added to provide a low-impedance path for the signal at the operating frequency.
