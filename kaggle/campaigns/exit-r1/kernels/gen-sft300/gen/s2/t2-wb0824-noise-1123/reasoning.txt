The binding constraint is the noise figure (nf_max_db), which is slightly over the specification. The original circuit uses a current-reuse topology with a shared DC path and a tuned load (L2+C2). However, the noise performance is limited by the noise contributions from the biasing network and the current mirror (NM3), as well as the lack of proper noise isolation between the input and the active devices.

The proposed solution modifies the topology to improve noise performance by introducing a separate noise-isolated biasing path for the NMOS input transistor (NM1), and by replacing the current mirror (NM3) with a direct NMOS connection to the DC path (VSS). This reduces noise coupling from the bias network into the signal path and improves the noise figure by minimizing the noise contribution from the current mirror. Additionally, a new NMOS transistor (ZN1) is added to provide a low-noise, noise-isolated path for the gate of the input transistor, further reducing noise degradation.
