To address this, I introduce an explicit input impedance tuning element by adding a shunt inductor (ZL1) between the input node (n0) and ground (VSS). This inductor provides a frequency-dependent impedance that can be tuned to improve the input matching at the target frequency (1.385 GHz), thereby increasing the s11_max_db margin.
