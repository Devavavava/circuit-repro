**Prediction**: s11_db improves by ~3.5 dB.  
*Reasoning*: The input node (n1) is connected directly to L1 and C1, forming a resonant input structure. However, the gate of NM1 (n2) is biased via R1-R2, making the input impedance sensitive to bias point and parasitics. Introducing PM3 (PMOS) with drain tied to n1 (input), gate to n2, source to VDD, creates a feedback path from output to input via the gate. This is a **source-degenerated PMOS feedback** that actively stabilizes the input impedance. The PM3 acts as a voltage-controlled current source pulling current from the input node, effectively increasing the input resistance and enabling better matching to 50Ω. The structure is similar to a common-gate amplifier with feedback, enhancing input match at the cost of some gain — but the binding metric s11_db is improved significantly due to better impedance scaling.


**Prediction**: s11_db improves by ~4.0 dB.  
*Reasoning*: The input node (n2) is currently connected to NM1 gate via R2 and to PM1 gate via R4. The lack of a proper input matching network causes the input impedance to be poorly matched. Introducing L3 (inductor) between n2 and n3 (which are both gate nodes) forms a **series resonant loop** with C2 (between n2 and n3). This creates a tuned input network: L3 + C2 resonates at 915 MHz, creating a low-impedance path at f0 that effectively shunts the input to ground at resonance, improving input match. The inductor L3 is placed between the two gate nodes, forming a loop that enhances the real part of the input impedance toward 50Ω. This is a classic technique in narrowband LNAs — using a resonant gate loop to achieve impedance matching. The structure is fully passive and adds no biasing complexity, making it a clean structural fix. The improvement is expected to be significant due to resonant input tuning.
