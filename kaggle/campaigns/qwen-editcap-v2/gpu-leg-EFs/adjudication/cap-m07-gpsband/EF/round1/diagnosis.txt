DIAGNOSIS: The LNA is failing due to poor input impedance matching (S11 -1.84 dB vs -12 dB spec), caused by a suboptimal LC tank configuration and gate resistor loading. The series L1-C1 input network is misaligned for resonance at 1.58 GHz, while R2 (180kΩ typical) creates a high-impedance gate bias node that degrades return loss. The diode-connected NM2/PM2 biasing networks add unnecessary complexity and impedance mismatch.
